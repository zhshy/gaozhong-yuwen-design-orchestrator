# 八类课型的最小模板

> **为什么要有这个文件**：母本的十二节结构、三台阶、一节课一个主问题的写法，**只对单篇精读成立**。
> 单元起始课、活动课、整本书阅读、梳理探究这四类，教学点不是"从一篇课文里挖出来的"，硬套单篇模板会得到一份结构正确但不能用的设计。
>
> 本文件给每一类一个**最小骨架**——不追求完备，只求"照这个走，不会写成四不像"。

---

## 1. 五类为什么不够：实测依据

对国家中小学智慧教育平台**必修上册 79 节课例**（8 个单元全覆盖）按课题名与内容归类，实际分布如下：

| 课型 | 节数 | 占比 | 原 5 类里有吗 |
|---|:-:|:-:|---|
| 单篇精读 | 36 | 46% | ✅ |
| 活动·实践课 | 11 | 14% | ❌ |
| 单元起始课 | 8 | 10% | ❌ |
| 整本书阅读 | 7 | 9% | ❌ |
| 写作课 | 6 | 8% | △（有"作文讲评"，无写作指导课） |
| 联读·比较阅读 | 5 | 6% | △（算在"群文阅读"里，无模板） |
| 梳理探究·语言积累 | 5 | 6% | ❌ |
| 复习课 | 1 | 1% | ✅（有类别，无模板） |

**结论**：**近四成课例没有对应模板**。而缺的这四类，恰好是必修上册第四单元（家乡文化生活·活动课）、第五单元（整本书阅读·乡土中国）、第八单元（词语积累与词语解释·梳理探究）的**全部内容**——这三个单元按原规范无法交付。

## 2. 八类总表

| # | 课型 | 一句话判别 | 教学点从哪来 | 课时 |
|:-:|---|---|---|---|
| 1 | **单篇精读** | 一篇课文讲一课时以上 | 文本内部的矛盾与缝隙 | 1–2 |
| 2 | **联读·比较阅读** | 两篇及以上放在一起讲 | **篇与篇之间的差异**（不是各自的详解） | 1 |
| 3 | **单元起始课** | 一个单元的第一课时，先"看见整个单元" | 单元目标体系 ＋ 学习路径 | 1 |
| 4 | **活动·实践课** | 学生要走出文本去做事（调查、访谈、办展、朗诵会） | 活动流程中的**能力节点** | 1–3 |
| 5 | **整本书阅读** | 读一整本书，不是节选 | 全书的结构、读法、议题 | 1–3（含导读／推进／交流） |
| 6 | **写作课** | 以"写"为产出，不是以"读"为产出 | 写作困难点（立意／结构／语言） | 1–2 |
| 7 | **梳理探究·语言积累** | 以语言现象本身为对象（词语、语法、修辞、文体知识） | 语言现象的规律 | 1 |
| 8 | **复习课** | 已学内容的整合与迁移 | 知识网络中的断点 | 1 |

**分流口诀**：

> 看学生的**最终产出**是什么。
> 产出一段**对文本的理解** → 1／2；产出一份**单元学习计划** → 3；
> 产出一件**作品或一次活动** → 4；产出一份**整本书的读法** → 5；
> 产出一段**自己的文字** → 6；产出一张**语言规律的归纳表** → 7；产出一张**知识网络图** → 8。

## 3. 八类各自的最小骨架

每类给：**目标怎么写 / 教学点怎么排 / 与单篇模板的差异 / 最小骨架 / 常见坑**。

### 3.1 单篇精读

现有十二节模板**原文照用**，本文件不重复。要点只有一条：**教学目标条数＝教学点数，且不超过 3**。

### 3.2 联读·比较阅读

**与单篇的根本差异：教学点不在单篇内部，而在两篇的差异上。**

| 项 | 差异 |
|---|---|
| 目标 | 每条目标必须含**比较动作**（"比出……的不同"），不写"理解甲篇""理解乙篇"——那是两节单篇课 |
| 教学点 | **2 个以内**。联读课最常犯的错是把两篇各讲一遍，实际上了两节压缩课 |
| 主问题 | 全课一个主问题，且**必须跨篇**（"两篇都写了离别，为什么一个让人哭、一个让人笑"） |
| 母本第一节 | 加"**为什么把这两篇放在一起**"一段：文体／主题／写法／时代的哪一个共同点构成比较基础。**说不出共同点，就不该联读** |
| 母本第二节 | 教学定位改为**两篇在单元中的位置关系**（并列／对照／递进） |
| 任务单 | 任务一必为**并列对照表**（维度 × 篇目），维度 2–4 个，由教师给定 |
| 作业 | 迁移题必须是**第三篇**（课外的）用同一维度比较，不能还是这两篇 |
| 课件 | 每页**两栏对照**是主要版式，不做单篇的逐段赏析页 |

**最小骨架**：

```
一、依据（任务群 / 水平 / 素养）
二、教学定位（＋ 为什么联读：比较基础是什么）
三、教学目标（≤ 2 条，均含比较动作）
四、教学重难点（难点在"比出差异"，不在"读懂单篇"）
五、课时安排（对照表占时最多）
六、情境任务链（一个情境，任务是"把两篇放在一张表里"）
七、主问题（跨篇）＋ 追问链
八、板书（双栏对照结构）
九、作业（迁移到第三篇）
十、风险点（典型错法：把两篇讲成两段，比较只做最后 5 分钟）
十一、检测与量规
十二、方向 × 学情
```

**常见坑**：比较维度由学生"自己找" → 45 分钟全耗在维度上，什么也没比出来。**维度必须教师给定**，学生的活是"填表并说明为什么"。

### 3.3 单元起始课

**本质是一节"单元导览"，不是提前讲课文。**

| 项 | 差异 |
|---|---|
| 目标 | 面向**单元**，不是单篇：说清本单元学什么、怎么学、学到什么程度 |
| 教学点 | 3 个固定位：① 单元人文主题与任务群定位；② 单元篇目之间的关系与学习路径；③ 本单元的**评价方式**（学生要知道最后怎么被评） |
| 母本结构 | 第二节"教学定位"**升格为全课主体**，其余节按导览需要取舍 |
| 任务单 | 任务一"读单元目录，给每篇标一句话"；任务二"画出单元学习路径图"；任务三"定我自己的单元学习计划" |
| 作业 | 一份**单元预习清单**（不是课文习题） |
| 课件 | 必须有**单元结构图**（篇目 → 关系 → 任务 → 评价）一页，且全单元后续课可复用 |
| 禁装 | **不许提前讲课文内容**——起始课讲完了，后面几节课就没悬念了 |

**最小骨架**：

```
一、依据（任务群在本单元的落点）
二、单元分析（人文主题 / 选文逻辑 / 与其他单元的关系）  ← 主体
三、单元学习目标（3 条，面向整个单元，不是本课时）
四、单元学习路径（课时分配表：哪几节、各解决什么）
五、本课时任务链（读目录 → 画路径 → 定计划）
六、单元评价方式（怎么算学完：任务单、展示、测评各占什么）
七、作业（单元预习清单）
八、检测与量规（评"路径图"和"计划"，不评课文理解）
```

**常见坑**：把起始课上成"第一课时的精读课"——课时用掉了，单元结构没建立，后面每节课都在补。

### 3.4 活动·实践课

**这类课的教学点不在文本里，在"做事"的流程里。**必修上册第四单元（家乡文化生活）全部属此类。

| 项 | 差异 |
|---|---|
| 目标 | 用**成果**描述（"能完成一份 800 字的人物访谈记录"），不用"体会""感受" |
| 教学点 | 拆成**活动的关键节点**：怎么定题 → 怎么获取材料 → 怎么整理 → 怎么呈现 |
| 母本第五节 | 时间表按**活动阶段**排（不是按"读—议—写"），且必须含**课外时间**，标明校内／校外 |
| 母本第七节 | 主问题改为**驱动性问题**（"我们能为家乡的哪一项文化做一份档案"） |
| 母本第十节 | 风险点必含**安全与伦理**：外出安全、访谈对象授权、引用规范、隐私 |
| 任务单 | 必含**过程记录表**（时间／地点／对象／获取了什么／遇到什么困难） |
| 作业 | 与活动成果**同一件**，不另出书面作业 |
| 课件 | 页数最少的一类（10–16 页），主体是**流程与模板**（记录表、访谈提纲样例），不是知识讲解 |
| 禁装 | **不许把活动课上成"活动介绍课"**——讲一节课怎么调查、学生一次也没调查 |

**最小骨架**：

```
一、依据（任务群：当代文化参与 / 跨媒介阅读与交流等）
二、活动定位（在本单元活动链中的位置）
三、活动目标（以成果表述，可评价）
四、活动重难点（难点通常是"获取真实材料"与"整理成有观点的呈现"）
五、活动流程与时间（校内 / 校外分列，含阶段成果检查点）
六、驱动性问题 ＋ 分解任务（3 个以内）
七、工具与模板（访谈提纲、记录表、呈现格式）
八、安全与伦理提示
九、成果评价量规（按成果维度，不按"参与度"）
十、风险点与应对
```

**常见坑**：目标写"培养语文实践能力"——不可观测、不可评价，等于没有目标。改成"能就一个文化现象完成 3 人访谈，整理出 2 条有分歧的说法"。

### 3.5 整本书阅读

**必修上册第五单元《乡土中国》是标准案例。**这类课的关键是**读法**，不是内容详解。

| 项 | 差异 |
|---|---|
| 目标 | 分三层：① **读下去**（进度与计划）；② **读进去**（概念与论证的把握）；③ **读出来**（迁移到现实问题） |
| 教学点 | 全书**结构**与**核心概念**，不是逐章讲。一章一课时是最典型的失败 |
| 母本第二节 | 教学定位改为**"本书在单元／任务群中的位置 ＋ 读法选择"**（学术著作的读法 ≠ 小说的读法） |
| 母本第六节 | 情境任务链跨**多课时**，含导读课／推进课／交流课三种课型，本课时只承担其中一种，**须写明是哪一种** |
| 任务单 | 必含**阅读进度表**（章／页／日期／一句话摘要）与**概念卡**（术语／原文定义／我的一句话解释／例子） |
| 作业 | 以**阅读推进**为主（读下一章 ＋ 概念卡），不以习题为主 |
| 课件 | 主体是**全书结构图**与**概念关系图**，不是章节摘要页 |
| 禁装 | 不许把整本书课做成"节选精读"——那就退回单篇了 |

**最小骨架**：

```
一、依据（整本书阅读与研讨任务群）
二、书目与版本（书名、作者、出版社、版次；版本必须统一，全班同一版）
三、本课时类型（导读课 / 推进课 / 交流课）与在全书计划中的位置
四、全书阅读计划（分几阶段、每阶段读什么、检查点是什么）
五、教学目标（≤ 3 条，覆盖读下去 / 读进去 / 读出来）
六、本课时任务链（2–3 个任务，均指向读法）
七、概念卡与阅读记录的要求
八、评价方式（过程性：进度表与概念卡；终结性：一份读书报告或议题探究）
九、风险点（读不下去的三个真实卡点及应对）
```

**常见坑**：**没有阅读计划，只有课时设计**。整本书课的成败在课外进度，课上只解决"读不下去"和"读不明白"。

### 3.6 写作课

| 项 | 差异 |
|---|---|
| 目标 | 指向**可修改的写作行为**（"能把三个分论点各自落到一个事例上，且事例与论点之间有解释句"），不写"提高写作水平" |
| 教学点 | 本课只解决**一个**写作困难点。写作课失败的首要原因是想一次解决三个 |
| 母本第五节 | 时间表必须给学生**动笔时间 ≥ 1/3**，且教师讲授 ≤ 1/3 |
| 母本第六节 | 任务链是"**诊断 → 方法 → 修改 → 互评**"四步，缺"修改"这一步就成了讲座 |
| 任务单 | 必含**病文或习作片段**（2–3 段）＋ 修改栏（留白）＋ 互评量表 |
| 作业 | 修改自己的习作（**同一篇**），不是另写一篇 |
| 课件 | 不超过 16 页；主体是**对照页**（改前 / 改后），不是写作知识罗列 |
| 禁装 | 不许出现"写作方法十大技巧"这类清单页——学生记不住，也用不上 |

**最小骨架**：

```
一、依据（任务群 / 课标中的表达与交流要求）
二、学情诊断（本班习作的真实问题，用 2–3 个原句作证）
三、教学目标（1–2 条，均为可修改的行为）
四、本课解决的一个困难点
五、课时安排（诊断 / 方法 / 修改 / 互评，动笔 ≥ 1/3）
六、任务链（病文诊断 → 方法提炼 → 当场修改 → 互评）
七、板书（方法的结构化呈现）
八、评价量规（修改前后的可检验差异）
九、作业（修改同一篇 ＋ 说明改了什么、为什么）
```

**常见坑**：**只讲不改**。没有当场动笔和互评，写作课就退化成阅读课。

### 3.7 梳理探究·语言积累

**必修上册第八单元（词语积累与词语解释）的课型。**对象是语言现象本身。

| 项 | 差异 |
|---|---|
| 目标 | 指向**归纳与解释**（"能从 10 个例句中归纳出词义变化的两种方式，并各举一例"） |
| 教学点 | 语言现象的**规律**，必须**从语料中来**——先给例子，后给规律，顺序不可反 |
| 母本第六节 | 任务链是"**收集语料 → 分类 → 归纳 → 解释**" |
| 任务单 | 必含**语料表**（例句／出处／我的分类）与**归纳栏**（留白） |
| 作业 | 在**生活中的语料**里找例（招牌、弹幕、广告、网络用语），不在课本里找 |
| 课件 | 主体是**语料与分类表**，不出现"现代汉语词汇知识"这类讲授页 |
| 禁装 | **不许先讲规律再举例**——那是"验证"不是"探究"，学生没有归纳的机会 |

**最小骨架**：

```
一、依据（语言积累、梳理与探究任务群）
二、学情（学生已有的语言经验与常见误解）
三、教学目标（≤ 2 条，均为"能从语料中归纳出……"）
四、教学重难点（难点：分类标准的确定）
五、课时安排（收集 / 分类 / 归纳 / 解释）
六、任务链（给语料 → 定标准 → 分类 → 归纳规律 → 解释例外）
七、板书（分类树或对照表）
八、检测与量规（评"归纳出的规律能否覆盖全部语料"）
九、作业（在生活语料中找新例，检验规律的解释力）
```

**常见坑**：把梳理探究上成知识讲授——学生记住了术语，没做过归纳。

### 3.8 复习课

| 项 | 差异 |
|---|---|
| 目标 | 指向**整合与迁移**（"能用同一套框架分析本单元三篇的不同写法"），不写"巩固本单元知识" |
| 教学点 | 知识网络中的**断点**（学生上次错在哪），不是重讲一遍 |
| 母本第二节 | 教学定位改为**本单元（或本专题）的知识结构 ＋ 已发现的断点** |
| 母本第五节 | 时间表：学生活动 ≥ 2/3，教师只做点拨 |
| 任务单 | 必含**知识网络图**（留白由学生补全）与**错题归因栏** |
| 作业 | **变式题**（同一考点的不同问法），不是原题重做 |
| 课件 | 不超 16 页；主体是**结构图与变式对比**，不做知识点复述 |
| 禁装 | 不许"从头再讲一遍"——复习课最普遍的失败 |

**最小骨架**：

```
一、依据（本单元对应的任务群与水平要求）
二、学情（断点清单：上次检测暴露的 2–3 个具体问题）
三、教学目标（≤ 2 条，指向整合与迁移）
四、知识结构（本单元的概念网络）
五、课时安排（学生活动 ≥ 2/3）
六、任务链（补网络图 → 归因 → 变式练习 → 互评）
七、板书（知识网络）
八、检测与量规（变式题的对错 ＋ 归因是否准确）
九、作业（变式题）
```

**常见坑**：复习课上成"第二次新授课"。

## 4. 单元整体设计：是**设计尺度**，不是课型

原 `课型.类别` 里混着"单元整体"，它与上面八类**不是同一层概念**——八类是**一节课的类型**，单元整体是**一次设计覆盖的课时范围**。

处理方式：

- 在课情卡里单列一个字段 **`设计尺度`：单课时（默认）／单元整体**，不要塞进 `课型.类别`。
- `设计尺度 = 单元整体` 时：**先出单元规划（单元目标体系 ＋ 课时分配 ＋ 单元评价），再逐课时出设计**；每一课时仍从上面八类里选一类。
- 单元规划的最小骨架：单元目标（3 条，覆盖任务群要求）→ 选文逻辑 → 课时分配表（几节课、各属哪类课型、各解决什么）→ 单元评价（过程 ＋ 终结）→ 单元作业结构。
- **一处已知张力（必须向用户说明）**：课标以任务群组织课程，而 `wang-rongsheng-reading-design` 对"大单元／群文／项目化"持审慎立场。做单元整体设计时**两条路都给出、说清代价，由用户定**，不要假装没有分歧（见 `SKILL.md` 第三节）。

## 5. 与流程的对接

| 课型 | 母本结构调整 | 对应模块 |
|---|---|---|
| 1 单篇精读 | 无（十二节原样） | 全流程 |
| 2 联读·比较 | 第二节加"比较基础"；目标 ≤ 2 条 | 同上 |
| 3 单元起始 | 第二节升格为主体；五／六／七节按导览重写 | 同上 |
| 4 活动·实践 | 第五节含课外时间；第十节含安全伦理 | 同上 |

**共同不变的两条**（八类都适用，不因课型放宽）：

1. **一节课一个主问题**（活动课为"一个驱动性问题"，写作课为"一个困难点"，整本书课为"一个读法问题"）。
2. **目标条数＝教学点数，且 ≤ 3**（精品课模式为 ≤ 3 条且不要求维度不重复）。
