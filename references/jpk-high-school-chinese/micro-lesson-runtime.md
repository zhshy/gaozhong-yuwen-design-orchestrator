# 微课视频运行稿

> **本技能产出运行稿，不产出成片。**
> 运行稿 ＝ 分镜 ＋ 时间轴 ＋ 画面设计 ＋ 教师语言 ＋ PPT 页次 ＋ 出镜／屏幕关系 ＋ 学生任务。
>
> 本文件是 **门禁九视频门禁** 与**红线 21** 的判据来源。

---

## 1. 先解决一个矛盾：课堂时间表与微课时间表

**问题**：既说"不能拿普通课堂的时间表直接录成视频"，又要求提交完整的教学设计——那么**课堂时间表还要不要**？

**本技能的处理：两者并存，互为约束。**

| | 教学设计（提交件 ①） | 微课运行稿（提交件 ⑤） |
|---|---|---|
| **按什么时长设计** | **完整一节课** | **微课时长** |
| **时间表** | 七列时间项，Σ ＝ 课时总时长 | **微课环节时间轴** |
| **为什么** | "教学设计"本身是提交件，且官方要求"突出课堂实效"——**压成三段的课撑不起这一项** | 微课是独立呈现形式，有自己的节奏 |

**关键：微课时间轴不是把课堂环节除以 3。**

> ❌ 错误做法：课堂 45 分钟 → 微课 15 分钟 → "每个环节时间 × 1/3"
> ✅ 正确做法：**按微课自己的节奏重新排**（见 §4）——保留核心问题、核心任务、核心证据、迁移出口，其余全部舍去。

**硬约束（红线 21／门禁九）**：

```
微课环节 中的学生任务集合  ⊆  课堂设计的学生活动集合
```

- 视频里出现的每一个学生任务，**必须**在课堂设计里已经存在（编号可对应）。
- **视频里冒出课堂设计中不存在的新任务 → 阻断。**
- **反向不算违规**：课堂里有、视频里没有的学生活动，正常（微课只取核心段）。

**为什么单向**：微课是课堂核心段的呈现。如果视频里凭空长出一个新任务，说明**视频和教学设计是两套东西**——这正是精品课最容易被查出的一类硬伤。

## 2. `微课运行稿` 结构

```yaml
微课运行稿:
  时长: { 目标: "", 最短: "", 最长: "" }   # 由用户/本地通知给定；本技能不规定技术参数
  环节序列:
    - 编号: 微课环节一
      时刻: { 起始: "00:00", 结束: "01:20" }
      目标编号: 目标一
      教学点编号: 教学点一
      教师: { 动作: "", 讲稿: "" }
      学生: { 动作: "", 预期产出: "" }
      画面: { 课件页次: PPT-03, 板书: "", 全屏: 是, 教师窗口: 否 }
      技术: { 启用: 否, 理由: "" }
      证据: ""
```

**字段要点**：

| 字段 | 要求 |
|---|---|
| `时长` | **本技能不规定**目标时长与上下限——由用户或本地通知给定。给不出就留空并标注，**不要编一个数** |
| `时刻` | 起止时刻，格式 `MM:SS`。**段与段之间不留空档**（后段起始 ＝ 前段结束） |
| `目标编号` | 该段服务于哪个目标。**一个段最多挂一个目标**，挂不上说明这段可以删 |
| `教学点编号` | 同上，对应教学点 |
| `教师.讲稿` | **可直接照读**的教师语言。不是"讲解本段大意"这种说明 |
| `学生.动作` | 学生**做什么**。整段只有教师动作 → 不通过（见 §3 判别） |
| `学生.预期产出` | 学生产出什么形态（一句话／圈画痕迹／表格） |
| `画面` | `课件页次` 指到具体页次；`全屏` 与 `教师窗口` 互斥优先（全屏时不叠教师画面） |
| `技术` | 若该段用技术，`理由` 必填，且须与 `technology-fit.md` 的五问一致 |
| `证据` | 该段产生的学习证据（可为空，但**连续三段为空**要检查是否只是"讲"） |

**编号纪律**：`微课环节一` 起顺序编号，**一旦定下不许中间插入改号**——课件页次与任务单编号都引用它。

## 3. 一段视频的合格判据

逐段过四个问题：

1. **这一段挂在哪个目标上？** → `目标编号` 空 → 删
2. **学生在这段里做什么？** → 只有教师讲、学生无动作 → **需要一个理由**（见下）
3. **学生产出什么？** → 说不出 → 这段只是"过场"
4. **这段的画面是什么？** → `画面` 空 → 录制时无从下手

**关于第 2 条：允许"纯讲授段"，但必须说明**

微课里有纯讲授段是正常的（问题建立、概念辨析）。但要求：

> 连续纯讲授段 **≤ 2 段**，且合计时长 **≤ 全片 1/3**。

超了就说明**这节微课在替学生上学**——与红线 2「学生的活动，不是教师的讲解」相冲突。

## 4. 节奏必须重排（本文件的核心方法）

**微课的节奏骨架**（六拍，顺序固定）：

```
问题建立 → 关键阅读/关键证据 → 学习任务 → 即时反馈 → 核心突破 → 迁移/检测
```

**一节高中语文精品微课只保留**：

> **1 个核心问题 ＋ 2–3 个学习任务 ＋ 1 个核心评价证据 ＋ 1 个迁移出口**

**逐拍说明**：

| 拍 | 干什么 | 常见错误 |
|:-:|---|---|
| **1 问题建立** | 让学生**当刻产生**疑问（不是"今天我们来学习…"） | 用教学目标当开场，学生无感 |
| **2 关键阅读/关键证据** | 把最能说明问题的那**一处**文本摆出来 | 铺太多背景，前 3 分钟没进入文本 |
| **3 学习任务** | 2–3 个任务，**每个都有学生动作** | 任务写成了"思考" |
| **4 即时反馈** | 给出评价口径，让学生知道自己到哪了 | 只给答案，不给"好到什么程度算好" |
| **5 核心突破** | 落在**一处**最要紧的语言现象上 | 面面俱到 → 面面不到 |
| **6 迁移/检测** | 一个出口，回指核心问题 | 加一段"总结升华"式抒情 |

**四件"砍掉"清单**（微课时长不够时按此顺序砍）：

1. 砍**过渡语与寒暄**
2. 砍**第二个任务**（保留最核心的一个 ＋ 一个迁移）
3. 砍**拓展背景**（作者生平、文学史地位等）
4. **最后一件事才是砍学生活动**——且砍掉后必须在课堂设计中保留，不能改成由教师代说

> ⚠️ **第 4 条的边界**：砍学生活动时，正确做法是**把该段整体从微课里去掉**（课堂上仍然做），**不是**让教师替学生说完。后者触发 `视频门禁二` **阻断**（见 `alignment.md` §6）。

## 5. 产出边界

**本模式产出**：

- 运行稿（分镜表）
- 时间轴（微课环节序列）
- 画面设计（PPT 页次、板书、全屏/教师窗口关系）
- 教师语言（可直接照读）
- 学生任务（动作与产出）

**本模式不产出、也不规定**：

| 不做 | 为什么 |
|---|---|
| 视频时长与格式参数（多长、什么格式） | 属**制作规范**，见 `2026-rules.md` §5 |
| 分辨率／码率 | 同上 |
| 片头片尾模板 | 同上 |
| 字幕规范 | 同上 |
| 文件体积与命名 | 同上 |
| 上传限制 | 同上 |
| **生成 MP4** | **本技能不声称生成视频文件**——只产出运行稿，成片由录制环节完成 |

**交付时必须主动说**：

> "我出的是**运行稿**——每一段讲什么、学生做什么、画面是什么、教师说什么，都写到位了。**录制、剪辑、成片参数**这些不在这份运行稿里，请交给录制环节。"

## 6. 与其它材料的对接

| 对接对象 | 要求 |
|---|---|
| **教学设计** | `微课环节.学生.动作` 必须能在课堂设计的活动中找到对应（§1 硬约束） |
| **学习任务单** | 视频中出现的任务，**编号与任务单一致**（`检测任务一` 对 `检测任务一`） |
| **课件** | `画面.课件页次` 必须指向课件里**真实存在**的页次（门禁八一致性） |
| **作业练习** | §4 第 6 拍的"迁移出口"与作业的迁移题**同源**，不是两份不同的迁移 |
| **技术适切** | `技术.理由` 与 `technology-fit.md` 五问的结论一致 |

## 7. 常见违规

| 违规 | 为什么错 |
|---|---|
| **把课堂环节除以 3** | 微课节奏是重排的，不是等比例压缩（§1） |
| **视频里出现新任务** | 违反 `微课环节 ⊆ 课堂` 硬约束，阻断（§1） |
| **教师替学生说结论** | `视频门禁二` 阻断——精品课最需要防的一类失败（`alignment.md` §6） |
| **纯讲授段过长** | 连续 > 2 段或合计 > 1/3 → 替学生上学（§3） |
| **写死技术参数** | 本技能不规定，写了会随年度通知变化而失效（§5） |
| **声称能生成视频** | 不实陈述（§5） |
| **段落挂不上目标** | 该段可删；留着占时长（§3 第 1 问） |
| **时间轴有断档** | 录制时无从对齐（§2） |

## 8. 检查清单

- [ ] `时长` 来自用户或本地通知；**给不出就留空标注，没有编数**
- [ ] 每段 `目标编号` / `教学点编号` **非空**
- [ ] 每段 `学生.动作` **非空**；若为纯讲授段，已计入"连续 ≤ 2 段、合计 ≤ 1/3"
- [ ] 每段 `画面` **非空**，`课件页次` 指向课件真实页次
- [ ] `教师.讲稿` 是**可直接照读**的话，不是"讲解大意"
- [ ] 时间轴**无断档**（后段起始 ＝ 前段结束）
- [ ] **`微课环节学生任务 ⊆ 课堂学生活动`** 已逐段比对过
- [ ] 全片只保留 **1 个核心问题 ＋ 2–3 个任务 ＋ 1 个核心证据 ＋ 1 个迁移出口**
- [ ] 砍时长时，**没有**把学生活动改成教师代说
- [ ] 全篇**没有**任何技术参数（时长参数、分辨率、码率、字幕、命名）
- [ ] **没有**声称生成 MP4
