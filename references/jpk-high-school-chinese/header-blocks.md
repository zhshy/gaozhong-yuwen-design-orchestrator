# 提交件首屏信息表（三件共用）

> **为什么单列一个文件**：教学设计、学习任务单、作业练习三件提交件，**首屏都是固定表格**，不是正文。
> 表格是平台模板的一部分，**空着交上去评委会直接看到缺项**；而这份表格里的字段，一半来自第 0 步的课情卡，一半只在这一处出现（如课例编号、出版社、出版日期）。写在这里，三件共用一套口径，避免各写一遍、互相不一致。
>
> **判据来源**：本文件是 `submission-checklist.md` 三（五件材料）与 `quality-gates.md` **门禁十（完整件门禁）** 的首屏判据；一致性比对的断链类型沿用 `material-consistency.md` §1。

---

## 0. 一句话纪律

> **首屏表格不进正文、不参与字数、不替代标题——但一个空格都不许留。**
> 拿不到的字段，填 `待核验` 并在表格下方单独一行说明"哪几项待核验、向谁核"，**不得为了"看起来完整"编一个**。

---

## 1. 三张表，分别装在哪一件

| 表 | 出现于 | 表头 |
|---|---|---|
| **A「课程基本信息」** | ① 教学设计　② 学习任务单　④ 作业练习　（三件**都要**） | 课例编号 / 学科 / 年级 / 学期 / 课题 / 教科书书名 / 出版社 / 出版日期 |
| **B「教学人员」** | ① 教学设计（**仅此一件**） | 授课教师（姓名·单位）/ 指导教师（姓名·单位） |
| **C「学生信息」** | ② 学习任务单　④ 作业练习 | 姓名 / 学校 / 班级 / 学号 |

**课件 `.pptx` 不要这三张表**——课件是投给学生看的，把课例编号打在标题页上是把内部编号泄到课堂。课件第一页只留课题名。

---

## 2. A 表｜课程基本信息（三件共用）

**版式**：两列窄表（字段名 | 填写内容），或 2×4 网格。**放在正文第一个标题之前**，即文档打开第一眼看到的就是它。

| 字段 | 填什么 | 从哪来 | 常见错法 |
|---|---|---|---|
| **课例编号** | 平台生成的编号，形如 `2020QJ10YWTB042`（年份＋学段学科代码＋序号） | `提交.课例编号`；平台报名后才有 | ① 自己编一个"看起来像"的编号；② 报名前就填上，交上去对不上 |
| **学科** | `语文` | 固定 | 写成"高中语文"（学段已单列） |
| **年级** | `高一` / `高二` / `高三` | `年级` | 写"高中一年级"或"必修上册"（那是教材，不是年级） |
| **学期** | `上学期` / `下学期` | `学期` | **误填成"下学期"**——这是实物里真实出现过的错（见 §5） |
| **课题** | **与官方节点名逐字一致**，含书名号与副标题 | `提交.官方节点名` | 与任务单、课件各写一套（门禁八横向断链） |
| **教科书书名** | 全称，如 `普通高中教科书·语文（必修上册）` | `教材` | 只写"语文必修上"（不是书名，是简称） |
| **出版社** | 全称，如 `人民教育出版社` | `提交.教材版本` | 写"人教社""人教版"（出版社 ≠ 教材版本） |
| **出版日期** | 到年月，如 `2019 年 6 月第 1 版`；有印次写印次 | `提交.教材版本` | 只写年份；把"印刷日期"当"出版日期" |

**三处必须同源**：A 表的「课题」与官方节点名、五件材料的文件名、母本标题，**四处逐字一致**。这是**门禁十的首屏第一项**，也是最常翻车的一项。

---

## 3. B 表｜教学人员（仅教学设计）

| 字段 | 填什么 |
|---|---|
| **授课教师** | 姓名 ＋ 单位（单位写到学校全称，不写简称） |
| **指导教师** | 姓名 ＋ 单位；可多位，逐行列出（区县教研员、教研组长） |

**两条纪律**：

- **指导教师不是"挂名"**——他要在评选环节能说清这节课的设计思路。填之前与本人确认，别事后补。
- **个人信息不上其他件**：教学人员表**只在教学设计**出现。任务单与作业练习面向学生，写教师姓名无意义；课件不写。

> 若为多人合作课例，另加一行「其他参与人员」并注明分工；不要塞进指导教师栏。

---

## 4. C 表｜学生信息（任务单 ＋ 作业练习）

| 字段 | 备注 |
|---|---|
| 姓名 | 留白供学生填写 |
| 学校 | 可预填本校全称 |
| 班级 | 留白 |
| 学号 | 留白 |

**为什么必须有这一张**：这两件是**学生手上真正用的纸**。任务单无姓名栏，收上来一叠分不清是谁的；作业练习无姓名栏，教师批改后无法归档。**"留白供填"本身就是体例要求**，不是多余的空格。

---

## 5. 实物依据与已知错例（写清楚，便于核对）

本节内容取自**国家中小学智慧教育平台已上线课例**的实物（79 节课例、316 个资源文件，教材为统编版必修上册）：

- 三件提交件**首屏均为「课程基本信息」表**，字段与 §2 一致；课例编号形如 `2020QJ10YWTB042`（批次＋学段学科代码＋流水号）。
- 教学设计在基本信息之后**紧跟「教学人员」表**；任务单与作业练习在基本信息之后紧跟**「学生信息」表**。
- **已知错例（不是我们编的，是实物里就有的）**：
  - 同一节课的**课题名写成两套**（一处"诗化小说连读课"、一处"联读——青春中国的时代印记"）——正是门禁八的横向断链。
  - **学期栏误填"下学期"**，而该册为必修上册（第一学期用书）。
  - 任务单**只有 2 页、无「推荐的学习资源」**，评选理由中被指为"材料单薄"。

> ⚠️ **版本待核验**：以上模板栏目取自 2020 年度批次实物。**2026 年度平台的模板是否改版，须以当年平台下载的模板文件为准。**
> 交付时照此说：**"首屏按往届实物模板做全了；若今年平台模板栏目有增减，以平台文件为准，我按新模板重排一遍即可。"** 不要声称"这就是今年官方模板"。

## 6. 与课情卡、门禁的对接

| 首屏字段 | 课情卡字段 | 缺失时 |
|---|---|---|
| 课例编号 | `提交.课例编号` | 标 `未提供`，表格内写"待平台生成" |
| 学科 / 年级 / 学期 | `学科` / `年级` / `学期` | 必问（`年级`与`学期`属必问项） |
| 课题 | `提交.官方节点名` | **第 0.5 步未过则不得进母本**，此处无从填起 |
| 教科书书名 / 出版社 / 出版日期 | `教材` / `提交.教材版本` | 标 `待核验`，并在表下写明"教材版本待核对" |
| 授课教师 / 指导教师 | `教师.*`（若已知） | 标 `未提供`，交用户自填 |

**门禁十（完整件门禁）首屏四项**（缺一即 `阻断`，判据落在 `quality-gates.md` 门禁十）：

1. 三件都装了 A 表，且 **8 个字段无一为空**（可以是 `待核验`，不可以是空白）；
2. 三件的 A 表**逐字相同**（尤其课题、教科书书名、出版社）；
3. 教学设计装了 B 表、任务单与作业练习装了 C 表；
4. A 表的「课题」与官方节点名、母本标题**字符串全等**（不是"差不多"）。

## 7. 检查清单

- [ ] 三件提交件首屏都有「课程基本信息」表，**放在正文之前**
- [ ] A 表 8 个字段无空白（`待核验` 可，空白不可）
- [ ] A 表在**三件之间逐字相同**（课题／教科书书名／出版社尤其）
- [ ] 「课题」与官方节点名、母本标题**字符串全等**
- [ ] 学期与教材册次**对得上**（必修上册＝上学期；不分上下的册次按当地教学计划记，标 `待核验`）
- [ ] 出版社写全称，出版日期到年月（含版次／印次）
- [ ] 教学设计有「教学人员」表（授课教师 ＋ 指导教师，均含单位）
- [ ] 任务单与作业练习有「学生信息」表（姓名／学校／班级／学号）
- [ ] **课件里没有这三张表**
- [ ] 待核验项在表下单独说明，未用"看起来完整"的假数据填
