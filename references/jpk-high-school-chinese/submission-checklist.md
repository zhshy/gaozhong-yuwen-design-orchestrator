# 提交前终检清单（教学设计侧）

> 第 8 步收尾、`报送冻结` 之前的最后一遍。
> **只覆盖教学设计侧**——视频技术参数与素材版权不在此列（见 `2026-rules.md` §5）。

---

## 使用方式

- **逐条打勾，不许跳**。宁可慢一遍，不要撤回一次。
- 任何一条打不上勾 → **说出是哪一条、差在哪**，不要写"基本符合"。
- 本清单是**最后一道**，不是唯一一道。前面各文件的检查清单**都应已过**。

## 一、节点与依据（门禁一、门禁二）

- [ ] 官方节点名称是**从平台原文复制**的
- [ ] `官方节点名 === 申报节点名`，**字符串全等**（标点、空格、括号、数字写法都比过）
- [ ] 五件材料上的**课题名与节点名逐字一致**
- [ ] 教材记到**出版社／版次／册次**，且与学生实际用书核对过
- [ ] 依据链七跳**全部走通**（节点→教材→单元→任务群→水平→素养→目标）
- [ ] **节点与依据同源**（不是"节点是甲、依据是乙"）
- [ ] `来源` 三件齐全：URL ＋ 核对时间 ＋ 截图或原文摘录
- [ ] 节点 `状态` 为 `通过`（若为 `阻断`，**流程已停止**）

---

## 二、目标与教学评一致（门禁三、门禁四）

- [ ] 目标 **≤ 3 条**
- [ ] 每条目标都有：**行为动词 ＋ 教学点 ＋ 学习证据 ＋ 评价**
- [ ] **没有**"提高审美情趣／培养人文情怀／增强文化自信"单独作为目标
- [ ] 第 0 步 `交付模式` **确为 `精品课`**（维度放宽只在本模式生效）
- [ ] `目标 → 教学点 → 活动 → 证据 → 评价` **五节闭合**，缺任一无
- [ ] `教学评对齐矩阵` **十列**已填，编号全局唯一
- [ ] 断链检查**逐条过了**（`alignment.md` §6）
- [ ] **无**"视频里教师替学生说结论"的情形

## 三、五件材料（门禁五～门禁十）

### ① 教学设计

- [ ] 母本**十二节 ＋ 两附**齐全
- [ ] 第五节时间表**七列齐**、Σ ＝ 总时长（误差 0）
- [ ] **汇报乘了组数**、**切换未写 0**、**教师讲授·齐读·机动一列已填**
- [ ] 第十二节"主打方向那一行"**三格填满**
- [ ] 待核对事项单列在正文之前

### ② 学习任务单

- [ ] **与学案区分开了**（不是把学案改名）
- [ ] 八节齐全
- [ ] 每个任务四个引用字段非空（`编号` / `目标编号` / `教学点编号` / `证据`）
- [ ] 每处提问**留了 ≥ 2 行书写空间**
- [ ] 任务数 **2–3 个**
- [ ] 题干**没有结论**
- [ ] 禁装项**一项不出现**

### ③ 课件

- [ ] 页数 **≤ 20 页**；正文 **≥ 18pt**；每页正文 **≤ 30 字**
- [ ] **不出现**教学目标、设计意图、作业答案、方向备注、教师适配调整
- [ ] 任务顺序、主问题文字、板书层级、文本引用与母本一致
- [ ] 配图**能对应课文某一句**（说不出对应的就是装饰，不放）

### ④ 作业练习

- [ ] 每道题都有 `目标编号` 且**回指得上**
- [ ] 每道题的能力**课堂上教过／练过**
- [ ] 每题有 `学生产出`、`证据`、`量规`
- [ ] `量规` 档位描述**可检验**（无空洞评价词）
- [ ] 迁移题与任务单第八节、微课末段**同源**
- [ ] 三档**不强制齐全**

### ⑤ 微课运行稿

- [ ] `微课环节学生任务 ⊆ 课堂学生活动`**逐段**比对过
- [ ] 每段 `目标编号`、`学生.动作`、`画面` **非空**
- [ ] 纯讲授段**连续 ≤ 2 段、合计 ≤ 1/3**
- [ ] 时间轴**无断档**
- [ ] `教师.讲稿` 是**可直接照读**的话
- [ ] 全片只保留 **1 个核心问题 ＋ 2–3 个任务 ＋ 1 个核心证据 ＋ 1 个迁移出口**

## 四、五件套一致性（门禁八、门禁九、红线 25）

- [ ] 课题名称**五件逐字一致**，且 ＝ 官方节点名
- [ ] 编号体系（`目标/教学点/活动/检测任务/作业/微课环节/PPT`）**全套唯一**，无重号无错指
- [ ] 目标文字在母本与任务单之间**指向一致**（措辞差异已逐条说明）
- [ ] 任务编号与内容在母本／任务单／课件／微课**四处一致**
- [ ] 主问题文字**四处一致**
- [ ] 板书层级在母本与课件一致
- [ ] 文本引用口径统一（无"一处引删节版、一处引全文"）
- [ ] 作业题目与母本第九节一致
- [ ] 评价量规在母本／任务单自评／作业量规 **三处口径一致**
- [ ] 迁移出口三处同源

## 五、技术（门禁七、红线 23、24）

- [ ] 技术五问**逐问作答**，第 1 问是具体难点（不是"理解困难"）
- [ ] 第 5 问**明确二选一**（没有"差不多"）
- [ ] `技术价值` 已分档，且与第 5 问一致
- [ ] 技术操作时间**已计入七列时间项**的「切换组织」列
- [ ] 学生操作工具时间 **<** 语文任务时间
- [ ] 做过**删技术测试**，装饰性技术已删或降档
- [ ] 全篇**无**"必须使用 AI／技术亮点／技术赋能"表述
- [ ] 若涉及 AI：评价对象是**学生的评判与修改**，不是 AI 输出
