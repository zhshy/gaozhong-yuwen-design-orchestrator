# 作业练习（提交件 ④）

> 独立 `.docx` 提交件。
> 本文件是 **门禁六作业门禁** 与**红线 20** 的判据来源。

---

## 1. 检查优先级顺序（本模式对普通模式的实质修改）

**这一步是本次改动里最实质的一条。**

普通模式的检查顺序是"**基础／提高／拓展三档是否齐全**"——先看形式。

精品课模式改为：

```
① 目标回指  →  ② 课堂承接  →  ③ 是否产生学习证据  →  ④ 评价标准  →  ⑤ 才轮到分层
```

| 序 | 查什么 | 判据 | 不通过 |
|:-:|---|---|:-:|
| ① | **目标回指** | 每一道题能回指至少一个 `目标编号` | **删题** |
| ② | **课堂承接** | 该题检测的能力在课堂上**教过、练过** | **删题**（测了没教的东西是无效检测，红线 9） |
| ③ | **学习证据** | 学生的作答本身构成可评价的证据 | 改题或删题 |
| ④ | **评价标准** | 有明确的口径（答案要点／档位描述） | 补标准 |
| ⑤ | **分层** | 基础／提高／拓展三档 | **格式选项，不是设计目标** |

**核心判据（红线 20）**：

> **每一道题必须能回指至少一个 `目标编号`，回指不上就不留。**

**三档的地位变化**：

| | 普通模式 | 精品课模式 |
|---|---|---|
| 基础／提高／拓展三档 | **设计目标**（必须齐全） | **格式选项**（可选，按需） |
| 判断作业好坏的依据 | 三档是否齐全 | **能否回指目标、是否承接课堂、是否产生证据** |

**为什么改**：为凑三档而安排的题目，通常有一批**回指不上任何目标**——它们不是作业，是填充。
一道回指清晰、承接课堂的题，**优于**三档齐全但一半是凑数的题。

## 2. `homework` 结构

```yaml
作业:
  编号: 作业一
  目标编号: 目标二
  类型: [巩固, 迁移, 应用]
  任务: ""
  学生产出: ""
  证据: ""
  量规: []
```

**逐字段判据**：

| 字段 | 说明 | 不合格 |
|---|---|---|
| `编号` | `作业一` 顺序编号 | 无编号 |
| `目标编号` | 回指的目标 | **空 → 违规（红线 20）** |
| `类型` | 从 `巩固`（巩固）／`迁移`（迁移）／`应用`（应用）中选，**可多选** | 写成"基础题""提高题"（那是分档不是类型） |
| `任务` | 题目本身 | 题干含结论（同任务单 §5 一） |
| `学生产出` | 学生交什么 | 空 |
| `证据` | 该题产生的学习证据 | 空 |
| `量规` | 评价要点或档位描述 | 空 → 无法评 |

### `类型` 三型的含义（不要与"三档"混为一谈）

| 型 | 检测什么 | 例 |
|---|---|---|
| `巩固` 巩固 | 课堂所学的**直接再现／复述性运用** | 说出三处比喻各自的本体喻体 |
| `迁移` 迁移 | 把学到的方法用到**新材料**上 | 用同样方法分析另一段文字中的比喻 |
| `应用` 应用 | 在**写作／表达**中运用 | 写一段话，用两个比喻支持一个观点 |

**与三档的关系**：`类型` 是**功能**，三档是**难度**。两者不是一回事，**不要把它们对齐**（"基础题＝巩固、提高题＝迁移"这种对号是错的——巩固题也可以很难，迁移题也可以很浅）。

## 3. 与其它材料的对接

| 对接对象 | 要求 |
|---|---|
| **教学设计** | 作业回填母本第九节（分层作业），**不另起事实源** |
| **学习任务单** | 任务单第八节"课后迁移任务"与作业的**迁移题同源**，不是两份不同的迁移 |
| **微课运行稿** | 视频末段"迁移出口"与作业迁移题**同源** |
| **课件** | 课件**不出现作业答案**（红线 11） |

**"同源"的含义**：三处（作业、任务单、微课）说的是**同一件事**，各自表述可以不同，但**指向的学生能力与材料方向一致**。
同源不是复制粘贴——作业可以更难，微课可以只给方向。

## 4. 量规（`量规`）写法

**每一档都要有可检验的证据要求**（红线 10）。

| 不可用 | 可用 |
|---|---|
| "理解深刻" | "指出三处比喻各自的本体与喻体，且能说明相似点不在'都是常见事物'而在'都是人人验证过的自然事实'" |
| "语言优美" | "所用比喻与所支持的观点之间有明确相似性，且读者不需解释即可看出关联" |
| "分析到位" | "分析落在具体语句上，能指出是哪几个字在起作用" |

**档位建议**：课堂作业用**三档**即可（未达标／达标／优秀），并**标注对应水平号**（必修默认**水平 2**）。

## 5. 分档与处理

| 情形 | 分档 | 动作 |
|---|:-:|---|
| 某题回指不上任何目标 | **提醒** | **删题**（红线 20） |
| 某题测的能力课堂没教 | **阻断** | 删题或补教学（红线 9） |
| 某题无 `学生产出` 或 `证据` | **阻断** | 补产出与证据要求 |
| `量规` 为空洞评价词 | **阻断** | 改为可检验的证据要求（红线 10） |
| 题干含结论 | **阻断** | 重写题干 |
| 三档不齐 | **不扣分** | 三档已是格式选项（§1） |
| 全篇只有客观题 | **提醒** | 检查是否与语文任务脱节 |

---

## 6. 常见违规

| 违规 | 为什么错 |
|---|---|
| **为凑三档而加题** | 三档已降为格式选项；凑出来的题通常回指不上目标（§1） |
| **按"基础＝巩固"对号** | `类型` 与难度是两个维度（§2 末） |
| **作业与任务单的迁移任务不是同一件** | 与门禁九精神冲突：出口应当唯一 |
| **作业量按"题数"衡量** | 应按"是否承接课堂"衡量；题多不等于学得多 |
| **量规写成评语** | 量规是**评价工具**，不是鼓励语（§4） |
| **课后作业重复课堂内容** | 重复不产生新证据，属无效作业 |

## 7. 检查清单

- [ ] 先查顺序：**目标回指 → 课堂承接 → 学习证据 → 评价标准 → 最后才看分层**
- [ ] 每道题都有 `目标编号`，且**回指得上**（红线 20）
- [ ] 每道题检测的能力**课堂上教过／练过**（红线 9）
- [ ] 每道题都有 `学生产出` 与 `证据`
- [ ] 每题都有 `量规`，且档位描述**可检验**（无"理解深刻"这类空话）
- [ ] 题干里**没有结论**
- [ ] 三档**不强制齐全**（已是格式选项）
- [ ] `类型` 与难度**没有**被错误对号
- [ ] 迁移题与**任务单第八节**、**微课末段**同源
- [ ] 作业回填**母本第九节**，没有另起事实源
- [ ] 课件里**没有出现作业答案**
