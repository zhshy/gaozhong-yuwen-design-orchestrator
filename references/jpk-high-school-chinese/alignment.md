# 教学评一致性（教学评对齐）

> 本文件管两件事：
> ① **依据链**怎么前移、怎么回溯（第 1 步）
> ② **`目标 → 教学点 → 活动 → 证据 → 评价` 闭环**怎么查断链（第 6 步、第 8 步）
>
> 它是门禁二与 **门禁四（最高优先级门禁）** 的判据来源。

---

## 1. 两条链的区别

普通模式的链条是**双向两段**：`课标 → 任务群 → 水平` 定依据，`教学点 → 课堂` 定实施，两者靠"对标"连接。

精品课模式把它改成**一条单链、每一跳可回溯**：

```
① 官方节点  →  ② 教材（出版社/版次/册次）  →  ③ 单元  →  ④ 任务群
                                                          ↓
                                        ⑦ 目标  ←  ⑥ 素养  ←  ⑤ 水平
```

**为什么要前移**：普通模式里，节点不属于流程（因为谁都能教任何一篇）。精品课里节点是**范围约束**——它决定了你能教什么，进而决定教材、单元、任务群。

**回溯判据（门禁二依据门禁）**：

> 从"目标"往回走，**每一跳都要能说出上一跳是什么**。任何一跳说不出，就是断链 → **阻断**。

**最要紧的一条**：

> **节点是甲、依据是乙 → 阻断。**
> 即：节点定的是《劝学》（必修上册第六单元），而依据链从"任务群 4 语言积累、梳理与探究"之类**别的单元**的条目接上来 → 直接阻断。节点与依据必须同源。

## 2. 依据链的写法（每跳一行）

| 跳 | 写什么 | 依据来源 |
|:-:|---|---|
| ① 官方节点 | `官方节点名` 原文 ＋ 核验结论 | `catalog-node.md` |
| ② 教材 | 出版社／版次／册次 ＋ 与**学生实际用书**核对结论 | `catalog-node.md` §2 |
| ③ 单元 | 单元序号与人文主题 | 教材目录 |
| ④ 任务群 | 18 个任务群中的哪一个（可多个，但有主次） | `gaozhong-yuwen-kebiao` |
| ⑤ 水平 | 对标学业质量水平几（必修默认**水平 2**；水平 4 供高考指向参考） | `gaozhong-yuwen-kebiao` |
| ⑥ 素养 | 主要落哪两方面（**不四方面平均用力**） | `gaozhong-yuwen-kebiao` |
| ⑦ 目标 | 由 ⑥ 与教学点共同生成 | 第 3 步教学点 |

**注意**：④ 与 ⑤ 的相对顺序是"任务群 → 水平"，但写作时按 ①–⑦ 的序号排。**不要跳过 ② 直接写 ③**——教材版本这一跳最容易被"默认统编版"糊过去，而它恰恰是官方明确要求的核对项。

## 3. 主链与派生链

```
              ┌─→ 检测任务（学习任务单）
              │
目标 → 教学点 → 活动 → 证据 → 评价  ├─→ 作业（作业练习）
              │
              ├─→ PPT 页
              │
              └─→ 微课环节（视频分镜）
```

**读法**：

- **主链**是设计逻辑：目标 → 教学点 → 课堂活动 → 学生产出 → 学习证据 → 评价。**这五节必须闭合**，缺任一 → 阻断。
- **派生链**是交付载体：任务单、作业、课件页、视频段各自承载主链的哪一段。它们是**同一份设计的四个视图**，不是四份独立内容。

**一句话判据**：

> **每一个交付件里的每一个元素，都要能指回主链上的某一节；指不回去的，删掉。**

## 5. 目标写法：本模式的一条实质放宽（**仅 `精品课`**）

> ⚠️ **本条只在本模式下生效。** 普通模式（`普通备课`）的硬规则不变，仍是"3 条目标各占一个不同的素养维度"。
> 判断依据是第 0 步 `交付模式` 字段——**不是"感觉这次比较特殊"**。
> （`交付模式` 是**交付模式**，取值 `普通备课` / `精品课`；**不要**与 `课型.模式`（讲读／自读／活动）混用。）

普通模式硬规则：**3 条目标必须各占一个不同的素养维度**。

精品课模式**放宽为**：

> 目标 **≤ 3 条**；每条必须**可观察、可评价、有学习证据、可回指教学点**；
> **不再要求三条分属三个不同维度。**

**理由**：精品课首先要"目标精准、能被活动实现、能被评价证明"。
`目标1＝语言建构与运用，目标2＝思维发展与提升，目标3＝思维发展与提升` 在语文精品课里完全可能合理。
**为凑维度而造目标，恰恰是评审最反感的。**

**放宽不等于放松**——下面四条一条不减：

| 仍必须满足 | 判据 |
|---|---|
| 可观察 | 有**行为动词**（说出／圈出／比较／写出／说明…） |
| 可评价 | 有对应的 `评价` 评价方式与证据要求 |
| 有学习证据 | 有明确的 `证据`（学生产出什么、存在哪里） |
| 可回指教学点 | 每条的 `教学点` 明确，条数＝教学点数 |

**仍然禁止**（门禁三目标门禁）：

> "提高审美情趣""培养人文情怀""增强文化自信"这类表述，**不得单独作为目标**——它们没有行为动词，也没有可检验的证据。

## 6. 断链检查表（第 6 步与第 8 步各跑一次）

| 断链形态 | 编号 | 分档 | 处理 |
|---|---|:-:|---|
| 某目标缺任务单载体 | `对齐门禁二` | **提醒** | 补任务单，或说明该目标不由任务单承载 |
| 某活动在视频中完全未体现 | `视频门禁一` | **阻断** | 改视频或改活动，**不许放着** |
| 视频里"老师自己讲答案"，而教学设计说学生比较 | `视频门禁二` | **阻断** | 见下 |
| 目标 → 教学点断裂（目标落不到某个教学点上） | `对齐门禁一` | **阻断** | 退回第 3 步 |
| 教学点 → 活动断（活动不服务于任何教学点） | `对齐门禁三` | **阻断** | 删活动或补教学点 |
| 活动 → 证据断（活动做了但拿不到学生产出） | `对齐门禁四` | **阻断** | 补产出要求 |
| 证据 → 评价断（有产出但无评价口径） | `对齐门禁五` | **阻断** | 补量规档位 |
| 作业某题回指不上任何目标 | `作业门禁一` | **提醒** | 删题（见 `homework.md`） |
| 任务单某任务回指不上任何目标 | `任务单门禁一` | **阻断** | 删任务或补目标（见 `task-sheet.md`） |

### 关于 `视频门禁二`（精品课最需要防的一种失败）

```
教学设计写着：学生比较三处比喻，圈画本体/喻体，自己得出结论
视频里却是：教师说"这三处比喻都说明了学习的重要性"
```

**这是本领域评审最容易失分、也最容易被本技能拦下的一类问题**：视频是"课堂核心段的呈现"，一旦视频把本该学生做的事改由教师代说，**五件材料表面上齐全，实际逻辑已经塌了**。

**处理**：阻断。要么改视频（恢复学生活动），要么改教学设计（承认这是讲授环节）——**不许用"视频时长有限"当理由**。时长不足的正确处理是**砍掉一个任务的呈现**，不是**替学生说完**。
