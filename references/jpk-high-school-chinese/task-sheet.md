# 学习任务单（提交件 ②）

> 独立 `.docx` 提交件。
> 本文件是 **门禁五任务单门禁** 与**红线 19** 的判据来源。

---

## 1. 先分清：`学案` ≠ `学习任务单`

**这是本模式最容易出错的一处**——直接把 `劝学_学案.docx` **改名交上去是不合格的**。

两者**从同一份母本派生**，是两个 **视图**，**不是父子关系**，也不能互相替代。

| 维度 | 学案（现有，普通模式） | 学习任务单（精品课提交件） |
|---|---|---|
| **覆盖面** | **全流程**：课前案 ＋ 课中案 ＋ 课后案 | **本节精品课的核心学习任务** |
| **体例** | 三段式 ＋ 11 栏目（版头／目标／重难点／学法指导／知识链接／疑惑／任务／小结／检测／作业／反思） | **六栏**（见 §2），**栏目名照平台模板**，不自拟 |
| **目标写法** | 学习目标（学生视角，1–3 条） | 同样是学生视角，但**每条必须挂 `目标编号`** |
| **任务粒度** | 按**课时环节**铺开 | 按**核心任务**组织，一节精品课建议 **2–3 个任务**，另有**课前任务**至少 1 项 |
| **与视频关系** | 无 | **任务必须与视频中的学生任务一致**（门禁九） |
| **是否独立成件** | 否（随四份 Word 一起出） | **是**，独立 `.docx` |
| **关系** | — | **两者同源，不是父子** |

**派生顺序**（两者都从冻结母本出，谁先谁后不影响）：

```
冻结母本
   ├─→ 学案（普通模式的交付物，精品课不提交）
   └─→ 学习任务单（精品课提交件 ②）
```

**一句话判据**：

> 学案是"这节课从头到尾学生用的一本册子"；
> 任务单是"**精品课要提交的那一份核心任务记录**"。
> 两者栏目不同、粒度不同、有没有 `目标编号` 也不同。

写任务单前，**先读一遍现有学案的体例**（`../xuean-shuoke-spec.md`），否则很容易把学案改个名就交。

## 2. 六栏结构（**栏目名照平台模板，不自拟**）

**这是本文件与上一版差别最大的一处，务必先看这一段**：任务单是**平台模板的填表**，不是自创体例。栏目名称、顺序由模板规定；我们能决定的是**每栏里写什么**，不能决定**有没有这一栏**。

### 2.1 六栏总表

| 栏 | 栏目名（照模板） | 装什么 | 硬要求 |
|:-:|---|---|---|
| 0 | **课程基本信息** | 课例编号／学科／年级／学期／课题／教科书书名／出版社／出版日期 | 8 字段无空白；三件提交件逐字一致。**细则见 [`header-blocks.md`](header-blocks.md) §2** |
| 0 | **学生信息** | 姓名／学校／班级／学号 | 留白供学生填。**见 `header-blocks.md` §4** |
| 一 | **学习目标** | 学生可理解版目标 | 每条挂 `目标编号`；不用"素养维度"这种术语 |
| 二 | **课前学习任务** | 上这节课**之前**要完成的事 | **至少 1 项**，须有明确产出；**不预习就没有课上任务的起点** |
| 三 | **课上学习任务** | 任务一～三 ＋ 四个子块（见 §2.2） | 本件主体。每任务四项必填，见 §3 |
| 四 | **推荐的学习资源** | 与本节课直接相关的文本、音频、影像、场馆、书目 | **至少 2 项**，每项写明"用来做什么"；**不许只贴链接** |

### 2.2 「课上学习任务」栏的内部结构

**原来的四项（学习情境／学习证据／当堂自评／迁移任务）不删，但降为子块**——它们不能另立一级栏，否则栏目与模板对不上，评委按模板找不到内容。

```
三、课上学习任务
  ├─ 学习情境（一句话，本栏的引导语，不单独成栏）
  ├─ 任务一        ← 四项必填（§3）
  ├─ 任务二
  ├─ 任务三（如需要）
  ├─ 我的学习证据   ← 子块：学生自填"这节课留下了什么"
  ├─ 当堂自评       ← 子块：对照目标逐条自评
  └─ 迁移出口       ← 子块：与作业的迁移题同源
```

| 子块 | 写法 | 为什么保留 |
|---|---|---|
| **学习情境** | 一句话讲清"我们要解决什么问题"；**不写设计意图** | 情境是任务链的入口，删了任务就变成散题 |
| **我的学习证据** | 学生自填：圈画／一句话／表格 | 把"学习证据"从教师评价口径变成**学生的自查动作**，是精品课任务单与普通学案差别最大的一处 |
| **当堂自评** | 对照目标逐条自评，**用可检验的档位描述**，不用"我学会了" | 支撑"教学评一致"可视 |
| **迁移出口** | 一个出口，与作业的迁移题**同源** | 与作业、微课末段三处同源（门禁九） |

**一句话记法**：

> **六栏是骨架（模板定的），四个子块是血肉（我们加的）。**
> 骨架少一根 → 不合模板；血肉丢一块 → 掉质量。两者的处理方式完全不同，别混为一谈。

### 2.3 三处最容易违反的

1. **「课前学习任务」被整栏跳过。** 实物里不少任务单直接从"学习目标"跳到"课上任务"，评选时被指"没有预习支撑，课堂起点悬空"。**这一栏必须真有内容**，且课上第一个任务要能接住它。
2. **「推荐的学习资源」只写"见教材"或只贴一个网址。** 每项都要写清**是什么、用在哪一步、怎么用**（例："《劝学》全文朗读音频（人教社配套），用于课前正音，听两遍后标出停顿"）。
3. **子块升格成一级栏。** 把"我的学习证据""当堂自评"写成与"任务一"平级的标题——模板里没有这两栏，序号会一路错位。

## 3. 每个任务必填四项（`任务` 结构）

```yaml
任务:
  编号: 检测任务一
  目标编号: 目标一
  教学点编号: 教学点一
  用途: ""            # 任务目的（学生能懂的说法）
  学生活动: []     # 圈画 / 比较 / 批注 / 表达 / 书写
  来源: ""             # 文本依据（第几段、哪一句）
  产出形态: ""           # 产出形态（表格 / 一句话 / 片段写作）
  证据: ""           # 期望的学习证据
  留白: 是            # 必须留书写空间（≥ 2 行）
```

**逐字段判据**：

| 字段 | 不合格 | 合格 |
|---|---|---|
| `编号` | 无编号 | `检测任务一`（与视频、作业、课件引用一致） |
| `目标编号` | 空 | `目标一`——**空 → 红线 20 违规** |
| `教学点编号` | 空 | `教学点一` |
| `用途` | "理解比喻论证" | "找出三处比喻，说明它们各自拿什么跟什么比" |
| `学生活动` | "思考""体会""感悟" | 圈画／比较／批注／书写／**说明** |
| `来源` | "课文" | "第二段'青，取之于蓝，而青于蓝'" |
| `产出形态` | "讨论" | "一句话（写在下面横线上）" |
| `证据` | 空 | "这句话 ＋ 圈画痕迹" |
| `留白` | `否` | **`是`**——书写空间 ≥ 2 行 |

**`留白` 是硬要求**：

> 每处提问之后**必须留 ≥ 2 行的书写空间**。
> 没有书写空间的任务单会退化成提纲，**学生当场用不了**。

## 4. 禁装清单

继承并收窄现有学案禁装清单（红线 14）：

> **教学目标、设计意图、预设答案、教师追问方案、教师活动、文本解读结论、方向备注、教师适配调整**——**以及把结论写进题干**。

**逐项说明为什么**：

| 禁装 | 为什么 |
|---|---|
| 教学目标 | 任务单上是**学生视角的学习目标**，不是教师的"教学目标"表述 |
| 设计意图 | 任务单是给学生看的；写意图等于把教师备课笔记发给学生 |
| 预设答案 | 学生看到答案，课堂讨论立即失效（红线 14） |
| 教师追问方案 | 同上 |
| 教师活动 | 任务单记的是**学生做什么** |
| 文本解读结论 | 结论由学生得出，不由任务单给出 |
| 方向备注／教师适配调整 | 这两项**只在教师端**（母本第七、十二节） |
| **把结论写进题干** | 见下 §5，**最隐蔽也最致命** |

## 5. 特别禁令（精品课任务单最常见的形式主义）

### ❌ 一、结论已经写在题干里

```
"请同学思考作者通过比喻表达了学习的重要性。"
```

**任务等于没布置**——学生只需要"表示同意"。正确写法是**把结论换成问题**：

```
"下面三处比喻，分别拿什么跟什么比？把'本体'和'喻体'填在表里，
 然后说说它们凭什么能支持'学不可以已'。"
```

**自检法**：把题干里的形容词和结论词圈出来，**如果圈出的词就是答案，重写**。

### ❌ 二、通篇选择题、填空题

**任务单不是习题集。** 语文任务单的主体应当是**阅读 — 比较 — 表达**，而不是"选出正确的一项"。

允许少量填空（如圈画后的归类），但**不得以客观题为主体**。

### ❌ 三、只有"思考""体会""感悟"这类无动作动词

这类词**不可观察、不可评价、不产生证据**。换成动作动词：

| 无动作 | 有动作 |
|---|---|
| 思考 | 圈出／写出／标出 |
| 体会 | 用一句话说明（写在下面） |
| 感悟 | 比较两处写法的不同，说出你的理由 |
| 品味 | 朗读这一句，说明你为什么在这里停 |

### ❌ 四、任务数与视频不一致

任务单是 `检测任务一～三`，视频里出现 `检测任务四` → **门禁五／门禁九违规**。
两处编号必须一一对应（`micro-lesson-runtime.md` §6）。

## 6. 分档与处理

| 情形 | 分档 | 动作 |
|---|:-:|---|
| 任务回指不上任何目标 | **阻断** | 删任务或补目标（红线 20） |
| 任务不产生学习证据 | **阻断** | 补产出要求 |
| 有任务无书写空间（`留白: 否`） | **阻断** | 补空间 |
| 题干含结论 | **阻断** | 重写题干（§5 一） |
| 与视频任务编号不一致 | **阻断** | 对齐编号（门禁九） |
| 任务数 > 3 | **提醒** | 检查是否该合并 |
| 任务数 = 1 | **提醒** | 检查是否粒度太粗 |
| 客观题占比过高 | **提醒** | 改为主观表达为主 |
| 出现禁装项 | **阻断** | 删除该项（§4） |
| **缺首屏「课程基本信息」或「学生信息」表** | **阻断** | 按 `header-blocks.md` 补齐 |
| **「课前学习任务」栏为空或只写"预习课文"** | **阻断** | 补具体任务与产出 |
| **「推荐的学习资源」少于 2 项，或只贴链接** | **提醒** | 补"是什么／用在哪一步／怎么用" |
| **四个子块被写成一级栏** | **提醒** | 归位到「课上学习任务」栏下（§2.2） |

## 7. 检查清单

- [ ] 与**学案**区分开了：**不是**把学案改名（§1 差异表逐项比过）
- [ ] **首屏两表齐全**：课程基本信息（8 字段无空白）＋ 学生信息（姓名／学校／班级／学号）
- [ ] **六栏齐全且栏目名照模板**：基本信息／学生信息／学习目标／课前学习任务／课上学习任务／推荐的学习资源
- [ ] **「课前学习任务」至少 1 项**，有明确产出，且课上第一个任务接得住它
- [ ] **「推荐的学习资源」至少 2 项**，每项写明是什么、用在哪一步、怎么用
- [ ] 四个子块（情境／学习证据／当堂自评／迁移出口）**在「课上学习任务」栏内**，未升格成一级栏
- [ ] 每个任务 **`编号` / `目标编号` / `教学点编号`** 三空非空
- [ ] 每个任务的 `学生活动` 是**动作动词**
- [ ] 每个任务的 `来源` 指到**具体段落或句子**
- [ ] 每个任务的 `产出形态` 是**具体产出形态**
- [ ] 每处提问后**留了 ≥ 2 行书写空间**
- [ ] 任务数 **2–3 个**（不是 1 个，也不超过 3 个）
- [ ] 题干里**没有结论**
- [ ] 通篇**没有**：教学目标／设计意图／答案／教师追问／教师活动／解读结论／方向备注／教师适配调整
- [ ] 任务编号与**微课视频**中的学生任务**一一对应**
- [ ] 当堂自评用的是**可检验的档位描述**，不是"我学会了"
- [ ] **迁移出口**子块与**作业的迁移题同源**
