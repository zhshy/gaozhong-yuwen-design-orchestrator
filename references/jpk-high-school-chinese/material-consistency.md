# 五件套材料一致性

> 第 8 步的核心工作。母本冻结前查的是"内部闭合"，这一步查的是"**五件材料彼此之间**是否自洽"。
> 本文件是 **JPK-08 课件门禁**、**JPK-09 视频门禁**与**红线 25** 的判据来源。

---

## 1. 为什么要单独查一遍

普通模式只有"母本 → 四份 Word"，四份都是**同一母本的视图**，一致性靠"以母本为准"一句话就能兜住。

精品课不同：**五件材料会产生彼此之间的新偏差**。

```
冻结母本 ─┬─→ ① 教学设计   ┐
          ├─→ ② 学习任务单 ├─→ 派生过程中各自被"改写"过
          ├─→ ③ 课件       │   （换说法、删字、调顺序、配图）
          ├─→ ④ 作业练习   │
          └─→ ⑤ 微课运行稿 ┘
                            ↓
                  ★ 本步：五件并排，逐字段比对
```

**派生过程必然引入差异**——任务单要写成学生语言、课件要压到 30 字以内、微课要重排节奏。差异本身不是问题，**问题是"同一件事在不同材料里变成了不同的事"**。

**所以顺序必须是**：

```
冻结内容（CONTENT_FREEZE） → 派生五件 → 一致性检查 → 提交冻结（SUBMISSION_FREEZE）
```

不许反过来：**先派生、再改母本**会导致五件全部作废重出。

## 2. 五件套一致性矩阵（逐字段比对）

**行＝要比对的字段，列＝五件材料。** 打 `—` 表示该件不承载此字段（不比对）。

| 要比对的字段 | ① 教学设计 | ② 学习任务单 | ③ 课件 | ④ 作业练习 | ⑤ 微课运行稿 |
|---|:-:|:-:|:-:|:-:|:-:|
| **课题名称**（＝节点名） | ✅ | ✅ | ✅ | ✅ | ✅ |
| **教材版本**（出版社/版次/册次） | ✅ | ✅（版头） | — | — | — |
| **课时数** | ✅ | — | — | — | — |
| **目标文字** | ✅ | ✅（学生版） | — | — | — |
| **教学点编号与表述** | ✅ | `teaching_point_id` | — | — | ✅ |
| **任务编号与任务文字** | ✅ | ✅ | ✅ | — | ✅ |
| **主问题文字** | ✅ | ✅ | ✅ | — | ✅ |
| **板书层级** | ✅ | — | ✅ | — | ✅（`visual.board`） |
| **文本引用**（引哪一段、引哪几句） | ✅ | ✅ | ✅ | ✅ | ✅ |
| **作业题目** | ✅ | — | — | ✅ | — |
| **评价量规** | ✅ | ✅（当堂自评） | — | ✅（`rubric`） | — |
| **迁移出口** | ✅ | ✅（第八节） | — | ✅（迁移题） | ✅（末段） |
| **编号体系**（OBJ/TP/ACT/TASK/HW/SEG/PPT） | ✅ | ✅ | ✅ | ✅ | ✅ |

> **编号体系那一行最容易漏**：全套材料共用**一套编号**。`TASK-01` 在母本、任务单、课件、微课里必须是**同一个任务**。

**逐列要点**：

| 材料 | 最常出问题的字段 |
|---|---|
| ① 教学设计 | 作为母本，**它是对照基准**；若它自身有断链，先用 `alignment.md` §6 修 |
| ② 学习任务单 | **目标文字**（学生版改写后偏离了原目标）、**任务编号**（与视频不一致） |
| ③ 课件 | **主问题文字**（为压字数改写后语义漂了）、**板书层级**、**文本引用**（引了删节版） |
| ④ 作业练习 | **迁移出口**（与任务单、微课不是同一件）、**评价量规**（与母本口径不同） |
| ⑤ 微课运行稿 | **任务编号**、**学生任务是否超出课堂设计**（JPK-09） |

## 3. 断链检查

### 3.1 三类断链

| 类 | 形态 | 编号 | 分档 |
|---|---|---|:-:|---|
| **横向断链** | 同一字段在两件材料里**指的不是同一件事** | `JPK-CONS-001` | **BLOCK** |
| **纵向断链** | 材料里的元素**回指不上母本**（凭空多出来的） | `JPK-CONS-002` | **BLOCK** |
| **数字断链** | 课题名、编号、课时、页次**对不上** | `JPK-CONS-003` | **BLOCK** |

### 3.2 逐件必查的九项

| # | 查什么 | 怎么查 |
|:-:|---|---|
| 1 | **课题名称**在五件里逐字一致，且＝**官方节点名** | 逐字比对，不用"意思一样" |
| 2 | **目标文字**在母本与任务单之间语义一致 | 任务单是学生语言，**允许改写措辞，不允许改变指向** |
| 3 | **任务编号与任务内容**在母本／任务单／课件／微课四处一致 | 按编号索引比对 |
| 4 | **主问题文字**在母本／任务单／课件／微课一致 | 若课件为压字数改了，**改回**或**同步母本**（以母本为准） |
| 5 | **板书层级**在母本与课件一致 | 层级数、并列关系都要对 |
| 6 | **文本引用**一致（引哪一段、哪几句、有无删节） | 课件引了删节版而母本引全文 → 标出 |
| 7 | **作业题目**与母本第九节一致 | 逐题比对 |
| 8 | **评价量规**在母本、任务单自评、作业 rubric 三处口径一致 | 档位名与判据都要对 |
| 9 | **`SEG 学生任务 ⊆ 课堂学生活动`** | 见 `micro-lesson-runtime.md` §1 |

### 3.3 一致性检查的输出

**不做"总体感觉一致"这种结论。** 逐项给结论：

```
一致性检查
├─ 课题名称       PASS  （五件逐字一致，＝节点名"劝学"）
├─ 教材版本       PASS  （人民教育出版社 2019 年版 必修上册，五件一致）
├─ 目标文字       PASS  （任务单为 3 处措辞调整，指向未变，逐条已核）
├─ 任务编号       BLOCK （微课有 SEG-06 指向 TASK-04，母本与任务单只有 TASK-01～03）
├─ 主问题文字     WARN  （课件压字数后删去"凭什么"三字，语义未变，建议同步）
├─ 板书层级       PASS
├─ 文本引用       PASS
├─ 作业题目       PASS
├─ 评价量规       PASS
└─ SEG ⊆ 课堂     PASS
```

**每一条都要写清"哪一件、哪一处、差在哪"**——写"基本一致"等于没查。

## 4. 修正方向铁律

**不一致时，一律以母本为准，改材料。**

| 情形 | 改哪边 |
|---|---|
| 课件与母本不一致 | **改课件**（母本是事实源） |
| 任务单与母本不一致 | **改任务单** |
| 作业与母本不一致 | **改作业** |
| 微课与母本不一致 | **改微课** |
| **母本本身有断链** | **退回第 6 步重冻**（CONTENT_FREEZE 作废，五件全部重出） |

**唯一例外**：如果发现母本错了（依据链断、目标回指不上教学点），**不许"以母本为准"糊过去**——那是把错误固化。
正确做法：**退回第 6 步，重走 CONTENT_FREEZE，五件全部重出**。这也正是"内容冻结"这四个字的意义。

## 5. 常见违规

| 违规 | 为什么错 |
|---|---|
| **只查"感觉一致"** | 一致性是可逐项打勾的，不是印象（§3.3） |
| **课件为压字数改语义** | 字数限制是形式要求，**不许用改语义来满足**（§4 例外） |
| **编号不统一** | `TASK-01` 指两件事，整条链就断了（§2 末） |
| **发现不一致就改母本** | 会把已冻结的内容反复解冻，五件永远出不来（§4） |
| **视频里出现新任务还放过** | `SEG ⊆ 课堂` 是硬约束，BLOCK（`micro-lesson-runtime.md` §1） |
| **拿删节版引文比对全文引文** | 教材删节与原文不同属正常，但**同一次提交里必须统一口径** |
| **五件齐全就认为过门禁** | 齐全只是 JPK-10；一致性是 JPK-08／09（`quality-gates.md`） |

## 6. 检查清单

- [ ] 五件**逐件**列出，**逐字段**比对过（不是抽查）
- [ ] 课题名称五件逐字一致，且**＝官方节点名**
- [ ] 编号体系**全套唯一**（`OBJ/TP/ACT/TASK/HW/SEG/PPT` 无重号、无错指）
- [ ] `SEG 学生任务 ⊆ 课堂学生活动` **逐段**比对过
- [ ] 目标文字的具体措辞差异**逐条说明**（允许改写，不允许改指向）
- [ ] 板书层级、主问题文字、文本引用三项在课件侧核过
- [ ] 迁移出口在**任务单第八节／作业迁移题／微课末段**三处同源
- [ ] 评价量规在**母本／任务单自评／作业 rubric** 三处口径一致
- [ ] 输出的是**逐项结论**（PASS／WARN／BLOCK ＋ 差在哪），不是"基本一致"
- [ ] 发现不一致时，**改的是材料不是母本**；若母本本身有错，**已退回第 6 步重冻**
