# 学科课程类精品课｜子目录导航

本子目录只服务**一个模式**：`精品课`（学科课程类精品课）。
普通备课模式（`普通备课`）**不读这里任何文件**——它的规格在 `references/` 上一层。

---

## 一、这个模式只做一件事

> 让**同一份教学设计母本**，变成一套**可提交的学科课程类精品课作品包**。

它**不改**教学理论，也**不重写**流程。底层五个技能（课标库 / 孙绍振 / 王荣生 / 肖培东 / 格式课件）在这个模式下**一律不改**。

差的只有三件：

| 差在哪 | 普通模式 | 精品课模式 |
|---|---|---|
| **起点** | 从篇目出发 | 从**官方目录节点**出发（第 0.5 步节点锁） |
| **交付** | 四份 Word ＋ 课件 | **四件套**（教学设计 / 学习任务单 / 课件 / 作业练习）＋ 微课运行稿 |
| **终点** | 母本冻结即完成 | 母本冻结 → 派生 → 一致性 → **提交冻结**（两次冻结） |

## 三、文件职责（11 个）

```
jpk-high-school-chinese/
├── README.md                  本文件：导航与加载顺序
├── 2026-rules.md              仅 2026 年度政策：类别／流程／材料清单／节点规则／年度变化
├── catalog-node.md            节点检索、核验、标题全等、教材核对、取证与保存
├── alignment.md               目标-教学点-活动-产出-证据-评价-任务单-作业-课件-视频 的关系
├── technology-fit.md          何时用/不用技术、功能分类、删技术测试、操作成本、学习增益
├── micro-lesson-runtime.md    微课结构、微课环节 时间轴、画面、教师语言、学生任务
├── task-sheet.md              学习任务单：八节结构、任务粒度、书写空间、答案隔离
├── homework.md                作业练习：目标回指、课堂承接、迁移、评价
├── material-consistency.md    五件套一致性矩阵与断链检查
├── quality-gates.md           门禁一～十 判据、分档、交付报告
└── submission-checklist.md    提交前终检清单（教学设计侧）
```

**分层原则**：

- `2026-rules.md` **只装随年份变的东西**（年度通知的类别划分、材料清单、时间节点、节点规则）。
- 其余 9 个文件装**不随年份变的方法**。
- 这样年度通知改版时，只改一个文件，其余不动。

## 四、范围外（本子目录**故意不装**的两类）

| 不装 | 为什么 | 谁来兜 |
|---|---|---|
| **视频制作规范**（时长／分辨率／片头／字幕／体积／命名／上传限制） | 本技能是**教学设计编排器**，不产出也不处理视频文件。把年度参数表塞进来，只会因编码参数变化被迫频繁升版 | 录制环节 ＋ 平台上传规则（由年度通知与平台页面约束） |
| **原创性与版权材料清单** | 这一项管的是**素材来源许可**（图片／音频／字体／引用／AI 生成素材），与"这节课怎么教"无关，属**作品合规**不属教学设计决策 | 提交环节 ＋ 学校教研与电教部门核验 |

**这两项是本模式的已知留白，不是遗漏。** 交付时必须**主动告知用户**："这两项请走录制与提交环节"，不要让用户以为本技能会替他解决。

---

## 五、一条不给退让的底线

> **节点核验拿不到证据时，不得降级为"推定通过"。**

九步流程里，其余各步都允许按证据强度分档（通过／提醒／阻断，甚至记 `待核验` 先往下走）；
**只有第 0.5 步例外**——拿不到官方节点证据就**停**，说明原因，等用户补证据。

理由：节点错了，后面所有工作都建立在一个不被接受的选题上。这是**返工成本最高、也最不该省**的一处。

详见 `catalog-node.md` §5「降级边界」。
