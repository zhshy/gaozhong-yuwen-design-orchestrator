## 二、六步流程与交接物

| 步 | 调谁 | 交出什么 | 交给谁 |
|---|---|---|---|
| 0 | — | 篇目/课型/课时/学情 | 全部 |
| 1 | 课标 | 任务群、水平、素养落点 | 定边界 |
| 2 | 孙绍振 | 关键点、还原表、核心提问 | 第 3、4 步 |
| 3 | 王荣生 | 教学点、三个台阶 | 第 4、5、6 步 |
| 4 | 肖培东 | 出口、主问题、朗读、生成预案 | 第 5 步 |
| 5 | 语文设计 | 九项成稿 + **课件 PPT** | 第 6 步 |
| 6 | 课标（量表）+ 王荣生（维度） | 检测任务、评分量规 | 用户 |

## 三、四个卡口（过不去就退回）

**卡口一（第 2 步出口）**
> 每个分析点落到具体语句了吗？
> 说不出是哪几个字、哪个动作，就是没做完。

**卡口二（第 3 步出口）**
> 教学点 = 文本关键点 × 学生疑难处，重合了吗？
> 学生本来就会的，不是教学点。

**卡口三（第 4 步出口）**
> 每个活动都能指回具体的字词句吗？
> 指不回去，就是飘了。

**卡口四（第 6 步出口）**
> 每个检测任务都能指回一个教学点吗？题型与体裁匹配吗？
> 测了没教的东西 = 无效检测；用客观题测散文的"怎么说" = 错配。

## 四、一节课检查清单（打勾交付）

**依据层**
- [ ] 任务群定位明确
- [ ] 对标学业质量水平几，写明
- [ ] 素养四方面只落主要两个，不平均用力

**文本层**
- [ ] 说清了"一望而知的是什么、一无所知的是什么"
- [ ] 至少一处还原、一处比较
- [ ] 每个判断都有原文语句支撑

**教学层**
- [ ] 教学点不超过 3 个
- [ ] 台阶不超过 3 个，且是"学的活动"
- [ ] 时长总和 = 课时总时长
- [ ] 未做文本外的思想教育

**课堂层**
- [ ] 只有一个主问题
- [ ] 教学出口来自文本内部
- [ ] 每次朗读都有依据
- [ ] 有 2–3 处学生答偏的追问预案

**格式层**
- [ ] 目标可观测（无"培养……情怀"）
- [ ] 情境来自真实生活/社会场景，非"假如你是古人"
- [ ] 板书用 ASCII 框图
- [ ] 作业三档难度真有区分
- [ ] 留了重点校 / 普通校分层参数

**课件层（第 5 步，课件版）**
- [ ] 页数 ≤ 15，**含标题页与小结页**
- [ ] 不出现教学目标、设计意图、预设应对、教师自述、作业答案
- [ ] 每页正文 ≤ 30 字，**台下 5 秒可辨**
- [ ] 全篇无小于 18pt 的字（正文目标 22pt）
- [ ] 四周留白 5%–10%，文字未顶到屏幕边缘
- [ ] 标题的位置 / 字号 / 颜色全篇统一
- [ ] 板书结构、任务顺序、主问题文字与教案一致
- [ ] **先交过「页—内容」清单并获用户确认，才生成 `.pptx`**

**检测层（第 6 步）**
- [ ] 每个检测任务都能指回一个教学点
- [ ] 先定了维度（测"看出"还是"看到"）
- [ ] 题型与体裁匹配（实用文可客观题 / 文学文本须开放题）
- [ ] 量规每档含可检验的证据要求
- [ ] 对标水平号明确且合理（必修默认水平 2）
- [ ] 设计了让个体作答成为全班讨论对象的环节
- [ ] 预判了未达标集中处与相应教学调整

## 五、三句话记住五个技能

- **课标**告诉你：教到什么水平算合格，以及怎么把它变成量表
- **孙绍振**告诉你：这篇文本真正难在哪
- **王荣生**告诉你：这节课只能教哪几个点，以及这节课该怎么测
- **肖培东**告诉你：怎么让学生自己走到那个点上
- **语文设计**告诉你：交出去的东西长什么样——教案的九项格式、以及**上课投屏的课件 PPT** 都在这里
