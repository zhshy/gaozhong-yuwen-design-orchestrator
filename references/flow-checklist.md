# 备课流程速查表

打印出来贴在备课本上的那一页。

---

## 一、我该调哪个技能？

```
用户要什么？
├─ 一节课（完整的）        → 本总控，走七步
├─ 文本怎么读             → sunshaozhen-text-analysis
├─ 该教什么（教学点）      → wang-rongsheng-reading-design
├─ 课堂怎么上（导入/提问） → xiaopeidong-qianqian-teaching
├─ 依据 / 任务群 / 水平    → gaozhong-yuwen-kebiao
├─ 检测题 / 评分量规       → gaozhong-yuwen-kebiao（水平转量表）
│                          + wang-rongsheng（测什么维度、选什么题型）
├─ 教案九项格式 / 板书 / 课时表 → chinese-lesson-design
├─ 四份 Word（教学设计/教案/学案/说课稿） → 本总控第 7.1 步
│                          ★ 母本没冻结不做 Word；四份必须分四份出
├─ 上课课件 / 把教案做成 PPT → chinese-lesson-design（配套 PPT 交付标准）
│                          ★ 母本没冻结不做课件；先交页面清单确认，再生成
└─ 作文批改                → gaoyi-writing-coach
```

> 五份成果**同源**：`教学设计` 是母本（十二节 + 两附），`教案`／`学案`／`说课稿`／`课件` 全由它派生。母本必须等第 6 步的检测与量规回填后才完整，所以**派生交付排在检测之后**（第 7 步）。

## 二、七步流程与交接物

| 步 | 调谁 | 交出什么 | 交给谁 |
|---|---|---|---|
| 0 | — | **LessonContext 课情卡**（七组字段，逐字段标 `confirmed`/`inferred`/`missing`/`needs_verification`） | 全部 |
| 1 | 课标 | 任务群、水平、素养落点 | 定边界 |
| 2 | 孙绍振 | 关键点、还原表、核心提问 | 第 3、4 步 |
| 3 | 王荣生 | 教学点、三个台阶（**用时按六类时间项拆**） | 第 4、5、6 步 |
| 4 | 肖培东 | 出口、主问题（**+方向备注**）、朗读、风险点（**三段式**） | 第 5 步 |
| 5 | 语文设计 | **教学设计母本**（十二节 + 两附）；教学目标准确来自第 3 步；**第五节含六类时间项、第十二节为方向 × 学情** | 第 6 步 |
| 6 | 课标（量表）+ 王荣生（维度） | 检测任务、评分量规 → **回填母本第十一节，母本冻结** | 第 7 步 |
| 7 | 本总控 + `tencent-docx` / `tencent-pptx` | **四份 Word**（教学设计 / 教案 / 学案 / 说课稿）+ 课件 `.pptx` | 用户 |

> **第 0 步不是走过场**：产出是一张 LessonContext 课情卡，每个字段都要标状态（`confirmed`／`inferred`／`missing`／`needs_verification`）。**填了不标状态＝编造（红线 7）**。细则见 [`lesson-context.md`](lesson-context.md)。

> **第 3 步的"用时"不要拍数字**：按六类时间项 + 教师讲授拆（独立阅读 / 小组讨论 / 汇报×组数 / 教师回应 / 书写 / 切换组织 / 教师讲授·齐读·机动），见 [`time-budget.md`](time-budget.md)。**漏掉"汇报 × 组数"与切换时间，是课堂超时最常见的两个原因。**

> **第 4、5 步有两个"别替用户定"**：主问题旁要附三方向问法差异（见 [`differentiation.md`](differentiation.md)）；第十二节是 3×3 方向 × 学情矩阵，不定唯一"最佳教案"。

## 三、四个卡口（过不去就退回）

**卡口一（第 2 步出口）**
> 每个分析点落到具体语句了吗？
> 说不出是哪几个字、哪个动作，就是没做完。

**卡口二（第 3 步出口）**
> 教学点 = 文本关键点 × 学生疑难处，重合了吗？
> 学生本来就会的，不是教学点。

**卡口三（第 4 步出口）**
> 每个活动都能指回具体的字词句吗？
> 指不回去，就是飘了。

**卡口四（第 6 步出口）**
> 每个检测任务都能指回一个教学点吗？题型与体裁匹配吗？
> 测了没教的东西 = 无效检测；用客观题测散文的"怎么说" = 错配。

## 四、一节课检查清单（打勾交付）

**输入层（第 0 步 · LessonContext）**
- [ ] 七组字段都已列出，**没有裸字段**（每个值都带四态标记之一）
- [ ] 每个 `inferred` 都写了推定依据
- [ ] 必问四项（篇目/单元、课型、课时数、学情层次）拿到值或已标状态
- [ ] 原文文字 / 课时数 / 教材版本年份三类，**未用 `inferred`**（只能 `confirmed` 或 `needs_verification`/`missing`）
- [ ] `missing` 项已问用户；未问到的列入「缺失项」并写明所用假设
- [ ] `needs_verification` 项列入「待核对」，交付物中字样未被撤下
- [ ] **教师画像**（偏好 / 回避 / 强项 / 弱项）已问过；未提供的标 `missing`，不凭空编
- [ ] 母本开头已回显本卡；四份 Word 页眉取自本卡

**依据层**
- [ ] 任务群定位明确
- [ ] 对标学业质量水平几，写明
- [ ] 素养四方面只落主要两个，不平均用力

**文本层**
- [ ] 说清了"一望而知的是什么、一无所知的是什么"
- [ ] 至少一处还原、一处比较
- [ ] 每个判断都有原文语句支撑

**教学层**
- [ ] 教学点不超过 3 个
- [ ] 台阶不超过 3 个，且是"学的活动"
- [ ] 台阶主要活动形态不与教师画像的 `avoids` 冲突
- [ ] 未做文本外的思想教育

**时间层**（细则见 [`time-budget.md`](time-budget.md)）
- [ ] 七列时间项都出现过（独立阅读 / 小组讨论 / 汇报 / 教师回应 / 书写 / 切换组织 / 教师讲授·齐读·机动；没有的写 **0**）
- [ ] **每处汇报写了组数**，总时长 = 单组时长 × 组数
- [ ] **切换 / 组织未写 0**（45 分钟的课通常 3–6 min）
- [ ] 每处学生阅读、讨论、书写都有分钟数
- [ ] Σ（七列）= 课时总时长 × 课时数，**误差 0**；且**分项之和 = 该环节小计**（两级都对）
- [ ] `students.class_size` 为 `missing` 时，是否按**抽样汇报**设计并在母本注明理由
- [ ] 超标削减已注明"削减了什么、为什么"（不许用压缩学生活动凑平）
- [ ] （可选）认知负荷未出现连续两个 3 级

**课堂层**
- [ ] 只有一个主问题
- [ ] 主问题下方有 **`> 方向备注：…`** 三句，指向不同层级（读懂 / 评价 / 迁移），各 ≤ 30 字
- [ ] 教学出口来自文本内部
- [ ] 每次朗读都有依据
- [ ] 有 2–3 处风险点，每处**三段式**（错误形态 → 误读机制 → 可直接照读的追问语）

**格式层**
- [ ] 目标可观测（无"培养……情怀"）
- [ ] 情境来自真实生活/社会场景，非"假如你是古人"
- [ ] 母本里板书用 ASCII 框图；**转入 Word 时改为层级表格**（不贴字符画）
- [ ] 作业三档难度真有区分
- [ ] 第十二节是 **3×3「方向 × 学情」矩阵**，主打方向那一行三格填满
- [ ] 教师画像为 `missing` 时，母本注明"本次未做教师适配"；**画像未进入学案与课件**

**文档层（第 7.1 步 · 四份 Word）**
- [ ] 母本已冻结（检测与量规已回填第十一节）——**未冻结不生成**
- [ ] 四份**分四份出**，未合并成一份多章节文档
- [ ] 文件名规范：`篇目_类型.docx`，不带书名号 / 空格 / 版本号
- [ ] 教学目标文字四份逐字一致；课时数据（**含时间项明细**）、主问题文字、方向备注、板书层级一致
- [ ] **学案未出现教学目标**（教师视角）、设计意图、预设与应对、答案与解读结论、方向备注、教师适配调整
- [ ] **学案六项齐全**：学习目标、学习重难点、学法指导、我的疑惑、归纳小结、学习反思
- [ ] **学案按体裁增补了栏目**，未用一套模板套所有课型
- [ ] **学案每处提问之后都有书写空间**（≥ 2 行）
- [ ] 学案用时 ≤ 30 分钟、课前案 ≤ 20 分钟；主体非选择题
- [ ] 教案"学生的活动"栏无空、无"听讲""配合"这类空话
- [ ] **说课稿第一节含所属学习任务群**（缺此层即旧范式）
- [ ] 说课稿每个环节都写了设计意图，无教师活动流水账
- [ ] **说课稿教学过程占全稿约一半篇幅**；字数与说课时长匹配
- [ ] Word 里无 ASCII 字符画板书
- [ ] 页眉含篇目 / 课型 / 课时 / 学情 / **教学方向**（四份逐字一致）；标题层级不超过三级
- [ ] 生成走 `tencent-docx`（未裸调 python-docx），且已打开 .docx 预览

> 学案与说课稿的栏目依据（含来源与可信度）见 `xuean-shuoke-spec.md`；凭印象编栏目是本流程最容易出的错。

**课件层（第 7.2 步，课件版）**
- [ ] 页数 ≤ 20，**含标题页、作者介绍页与小结页**
- [ ] 作者介绍页只留能进入文本理解的 1–2 个信息点，**未写成生平年表**
- [ ] 不出现教学目标、设计意图、预设应对、教师自述、作业答案、**方向备注、教师适配调整**
- [ ] 每页正文 ≤ 30 字，**台下 5 秒可辨**
- [ ] 全篇无小于 18pt 的字（正文目标 22pt）
- [ ] 四周留白 5%–10%，文字未顶到屏幕边缘
- [ ] 标题的位置 / 字号 / 颜色全篇统一
- [ ] 板书结构、任务顺序、主问题文字与教案一致
- [ ] **配图用影像蒸馏生成**（不用写实照片/图库素材），每份 3–5 张，插在留白充足的页面，全篇同一视觉系统、与课件同色系
- [ ] **每张配图可指回课文的具体语句**（保留的 2–4 个锚点说得出来）
- [ ] **作者介绍页形象为意象化处理并标注"示意图"**，非写实照片
- [ ] 配图未铺满整页当背景，未压叠正文
- [ ] **先交过「页—内容」清单并获用户确认，才生成 `.pptx`**

**检测层（第 6 步）**
- [ ] 每个检测任务都能指回一个教学点
- [ ] 先定了维度（测"看出"还是"看到"）
- [ ] 题型与体裁匹配（实用文可客观题 / 文学文本须开放题）
- [ ] 量规每档含可检验的证据要求
- [ ] 对标水平号明确且合理（必修默认水平 2）
- [ ] 设计了让个体作答成为全班讨论对象的环节
- [ ] 预判了未达标集中处与相应教学调整

## 五、一句话记住每个技能

- **课标**告诉你：教到什么水平算合格，以及怎么把它变成量表
- **孙绍振**告诉你：这篇文本真正难在哪
- **王荣生**告诉你：这节课只能教哪几个点，以及这节课该怎么测
- **肖培东**告诉你：怎么让学生自己走到那个点上
- **语文设计**告诉你：教案九项格式与**上课投屏的课件 PPT** 长什么样
- **总控第 7 步**告诉你：母本冻结后怎么切成**四份 Word**（教学设计 / 教案 / 学案 / 说课稿）——切分细则见 `deliverables-word.md`
