# 教学方向 × 学情 × 教师画像

**母本第十二节的填写依据，以及"提问旁边那句备注"怎么写。**

一句话：**不替老师定唯一的"最佳教案"，给可比较的几种设计方向。**

---

## 一、三个教学方向

同一篇文本，可以有三种都站得住的设计方向：

| 方向 | 重点 | 适合的语境 | **一句话差异**（供"提问旁备注"用） |
|:-:|---|---|---|
| **基础型** | 文言基础 + 核心内容 | 常规课；文言底子薄；课时紧 | 先读懂——**这句话在说什么，凭什么这么说** |
| **思辨型** | 核心问题 + 观点论证 | 常规课／公开课；学情中等以上 | 不止读懂——**这个论证站得住吗；换成你，会怎么写** |
| **高考型** | 论证结构 + 文言知识 + 迁移训练 | 复习课；高考指向；单元收束 | 读懂并且能用——**这个结构在考场上怎么认、怎么仿** |

**方向由什么定**（不给默认唯一解）：

1. **课标水平**——必修以水平 2 为底线（第 1 步）；
2. **教学语境**——常规课 / 公开课 / 复习课 / 高考指向（课情卡 `教学情境`）；
3. **课时数**——课时紧偏基础型，课时宽可走思辨型；
4. **教师画像**——见第四节；
5. **用户指定**——用户说了就以用户为准。

**用户没说方向时**：不要替用户定，把三个方向各给一句差异（见第二节），让用户挑。三个方向**共用同一份文本解读与教学点**（第 2、3 步不重做），差异落在目标层级、活动形态与提问问法上。

---

## 二、"提问旁边的一句话备注"怎么写

**位置**：母本第七节（主问题设计 + 追问链）中，**每个主问题之下**加一行 `> 方向备注：…`；第 4 步产出主问题时同步生成。

**模板**：

> 方向备注：基础型问法——……；思辨型问法——……；高考型问法——……。

**示例**（《劝学》主问题："为什么作者不用直接说理，而要连续使用这些比喻？"）：

> 方向备注：基础型问"这三个比喻分别说了什么，合起来说了什么"；思辨型问"删掉这三个比喻只留最后一句观点，说服力会有什么变化"；高考型问"这种'博喻 + 层递'的论证结构，在议论文里怎么认、怎么仿写一段"。

**三条要求**：

1. **三句必须真的不同**——指向不同目标层级（读懂 / 评价 / 迁移）。只换措辞不算；
2. **每句 ≤ 30 字**，是备注不是第二套设计；
3. 不要给三个方向都写一份完整教案——**备注是提示差异，不是三份方案**。用户挑定方向后，母本按该方向出，其余两句保留在备注里以备对照。

## 三、教学方向 × 学情矩阵（母本第十二节）

原"分层参数（重点校 / 普通校 / 薄弱校）"是**一维**的，只分学情；现扩为**二维**：行＝方向，列＝学情，共 9 格。

| 方向 ＼ 学情 | 重点校 | 普通校 | 薄弱校 |
|---|---|---|---|
| **基础型** | | | |
| **思辨型** | | | |
| **高考型** | | | |

**每格写什么**：写**该方向 × 该学情下的具体调整点**，写得出动作与取舍。不达标的样子：

- ❌ "适当加深难度""降低要求、注重基础"——空话，9 格可以套用同一句；
- ✅ "薄弱校 + 思辨型：把'论证是否站得住'拆成两步——先只问'这三个比喻能不能删'（可答），再问'删了会怎样'（需想），第二问允许只口头作答，不要求成文"

**收缩规则**：不必 9 格都填满。**主打方向那一行必须填满 3 格**；其余两行至少写清"若要改走这个方向，第一步改什么"。9 格全写满往往意味着没想清楚。

## 四、教师画像

**字段**（课情卡 `教师` 组，内部 YAML）：

```yaml
教师:
  偏好风格:      # 偏好：提问驱动 / 细读 / 活动驱动 …
  回避项:               # 回避：小组讨论 / 长时间讲授 / 角色扮演 …
  强项:            # 强项
  弱项:           # 弱项
  典型课时长:  # 常规课时长度，默认 45
```

**应用规则**：

| 字段 | 怎么用 |
|---|---|
| `偏好风格` | 偏好形态的活动**可以多排**（如偏好提问驱动 → 追问链可加长到 3–4 轮） |
| `回避项` | **不得**把它排进台阶的主要活动。若该教学点非它不可，**换形态**而不是硬上——小组讨论可换成"同桌两两互说 + 全班抽样"，并在母本注明替换理由 |
| `强项` | 可作为该环节的加分设计（不是必须） |
| `弱项` | 该环节**给更细的支架**：教师话术写清、预设追问给全、时间给宽 |
| `典型课时长` | 覆盖时间预算的默认课时长度（见 `time-budget.md`） |

**呈现边界（重要）**：教师画像属**教师个人信息**，只在**母本与教案**体现，**不进学案、不进课件**——学生会看到学案与投屏。

**缺省时怎么办**：课情卡里标 `未提供`，设计按"无偏好的通用方案"走，并在母本注明"**本次未做教师适配**"。不要凭空替教师编一个画像。

## 五、常见违规

1. **替用户定唯一方向**——不说"我给你三个方向"，直接出"最佳教案"。
2. **方向备注三句同义**——换措辞不换层级，等于没给选择。
3. **矩阵填成空话**——9 格套同一句"因材施教"。
4. **教师画像进了学案或课件**——把"该教师回避小组讨论"写给学生看。
5. **`回避项` 被无视**——明明回避小组讨论，台阶主要活动仍排小组讨论，只在备注里加一句"如有困难可调整"。
6. **凭空编教师画像**——用户没给就编一个"偏好启发式提问"，且不标来源。

## 六、检查清单

- [ ] 主问题下方有 `> 方向备注：…` 三句，且**三句指向不同层级**、各 ≤ 30 字
- [ ] 第十二节是 3×3 矩阵；**主打方向那一行填满**
- [ ] 每格是**可执行的动作与取舍**，不是"加深/降低难度"
- [ ] 教师画像字段已按 `已确认` / `未提供` 标注；`未提供` 时母本注明"未做教师适配"
- [ ] `回避项` 里的形态未出现在台阶主要活动中；若替换过，母本有替换理由
- [ ] 教师画像**未进入**学案与课件
- [ ] 页眉的"教学方向"与母本实际主打方向一致
