# 学案与说课稿规范

第 7.1 步派生件的体例依据。**这两份的分节规范在五个底层技能中均未定义**（`chinese-lesson-design` 只有教案九项），本节是现行落点，依据见文末「来源与可信度」。

编写时遵循一条判据：**每条规则都要能说出是哪一份校本文件或哪一级教研规则支持的**；拿不出依据的，标为"经验取值"，不写成硬规定。

---

# 第一部分：学案

## 1.1 定位（先定这个，再谈栏目）

学案是**学生视角的学习方案**——"学的方案"，不是教案的学生版，不是习题汇编，也不是知识清单。

三种定位对应的产物完全不同：

| 定位 | 产物特征 | 判断 |
|---|---|---|
| 教案的学生版 | 把教案里的答案挖空 | **错**。答案与设计意图都不该出现在学案上 |
| 习题汇编 / 知识清单 | 题目 + 知识点罗列 | **错**。这是"简单化、剪贴化、习题化"，被明令避免 |
| 学习方案 | 学生按步骤自主学、合作学的路线图 | **对**。这是"学生学会学习、学会合作、自主发展的路线图" |

一句话判据：**学案要把"老师要讲的"变成"学生要做的"。**

## 1.2 体例：三大模块

最通行也最稳的框架是"三案"，覆盖课前—课中—课后全流程：

```
课前案（预习案 / 课前导学） → 课中案（探究案 / 课堂探究） → 课后案（拓展案 / 训练案）
```

各校的变体（均取自正式校本文本）：

| 学校 | 体例名称 | 构成 |
|---|---|---|
| 四川省雅安中学（高中语文组） | **一寄语三案** | 寄语 = 学习目标 + 学习重难点 + 学习方法；三案 = 预习案 / 课中案 / 课后案 |
| 山东省济宁市实验中学 | 三案 | 课前预习案（基础知识回顾 / 阅读自学提纲 / 基础知识理解 / 难点疑点生成）+ 课堂探究案（学习目标 / 重点难点 / 情境创设 / 问题探究 / 反思感悟 / 跟踪练习）+ 课后拓展案 |
| 浙江省温州市龙湾中学（高二语文） | **五我结构** | 我阅读·我积累 / 我思考·我质疑 / 我合作·我探究 / 我练习·我提升（A 层基础演练、B 层延伸阅读）/ 我总结·我反思 |
| 山东省德州市实验中学（高二语文） | 三段 + 疑惑栏 | 自主学习案 / 课堂探究案 / 课后练习；自学案后设「我的疑惑」专栏 |
| 吉林省临江市（中小学教学管理常规细则） | 四部分 | 学习目标 / 课前预习 / 学习过程 / 课堂检测 |
| 河北衡水中学（转述资料） | 三部分 | 课前导学（含预习指导与预习题，课前完成、收交批阅）/ 课堂例题（课中讨论完成，**不留到课后**）/ 课堂练习（当堂巩固，下课收查） |

**本流程的取值**：采用"课前案 / 课中案 / 课后案"三段式（依据最广，各校变体均可映射），**不另造体例**。

## 1.3 必备栏目（八个基本内容）

教育教研部门归纳的"八个基本内容"，是学案栏目的最小完备集：

**学习目标 · 重点难点 · 学法指导 · 知识链接 · 学习过程 · 归纳小结 · 当堂检测 · 学习反思**

对照校本文本后，本流程采用以下栏目表。**加粗的六项是常被漏掉的**：

| 栏目 | 内容 | 说明 |
|---|---|---|
| 版头信息 | 课题 / 课号 / 年级学科 / 课时 / 主备人 / 审核人 / 编号 / 日期 | 青岛启迪、德州实验等校的固定格式；便于归档与集册 |
| **学习目标** | 学生视角，"能……"句式，1–3 条 | **是"学习目标"不是"教学目标"**；2–3 条为宜，不超过 3 |
| **学习重难点** | 学生视角的重难点 | 雅安中学的"寄语"里就包含重难点，属必备 |
| 课前案 | 知识链接（作者 / 背景 / 文体常识 / 旧知回顾）+ 预习任务 + **我的疑惑** | 文言文必备"知人论世"（作者与创作背景） |
| **学法指导** | 本课具体的学习方法提示（如"略读找每段主题句"） | 构成一条"学法线"，是导学案区别于习题集的关键 |
| 课中案 | 情境与任务 + 问题链（读什么—想什么—写什么） | 见 1.4 的阶梯设计 |
| **我的疑惑** | 学生提问栏，留白 | 雅安中学、德州实验、济宁实验均单设此栏 |
| **归纳小结** | 知识体系建构，**具体知识点留空由学生填** | 学案上留空，不是印好结论 |
| 当堂检测 | 5–8 分钟可完成 | 当堂完成、当堂反馈 |
| 分层作业 | 必做 / 选做 / 挑战三档 | 青岛启迪称必做题、选做题、思考题 |
| **学习反思** | "我的收获" / "存在的问题"，留白 | 龙湾中学「我总结·我反思」、雅安中学「我的收获」 |
| **评价反馈栏** | 小组互检 / 教师批阅 | 学案是"教学案"体系的一环，要留下被检查的痕迹 |

## 1.4 语文分体裁的栏目差异（这一节是语文特有的，必须区分）

**不同课型不能套同一个模板**——龙湾中学备课组的复盘原话是："是否每一种课型都适合这个统一模板？是否每一篇课文都需要导学案？"答案是都要按文言、诗歌、散文、写作分别处理。

| 体裁 / 课型 | 增补栏目 |
|---|---|
| **文言文 · 古诗文** | 正音正句（注音、朗读）、作者介绍、创作背景、文言知识点（实词 / 虚词 / 特殊句式）、段落与段意梳理、课文小结 |
| **诗歌** | 诵读标注（节奏 / 重音 / 停顿）、意象—情感对应表、诵读脚本 |
| **现代散文** | 语言品味批注栏、"景语—情语—哲语"递进表、比较阅读表 |
| **小说** | 人物—环境—情节关联表、多视角解读任务、细节描写分析栏 |
| **实用文 / 论著** | 论证结构梳理图、材料与观点对应表、概念辨析表 |
| **整本书阅读** | 阅读任务单、章节进度表、专题探究单 |
| **写作 / 语言积累** | 写作任务单、论点提炼模板、论据分类表、互评量表 |

## 1.5 任务的阶梯设计

任务难度应按"**感知 — 分析 — 创造**"三级分布，同一课时内三层并存：

| 层级 | 任务形态 | 组织形式 |
|---|---|---|
| 低阶（感知） | 圈画、概括、批注、正音、填空 | 个人独立完成 |
| 中阶（分析） | 对比、填表、探究原因、分析手法 | 小组合作 |
| 高阶（创造） | 辩论、改写、创作、撰写评论 | 全班或小组展示 |

原则：由易到难、**低台阶、高密度、缓坡度**；难度较大的内容走"引导 — 合作 — 探究"，基础内容走"自主阅读 — 自主练习"。

## 1.6 量化约束（有据可依，非经验估计）

| 项 | 取值 | 依据 |
|---|---|---|
| 每日学案总量 | ≤ 30 分钟 | 雅安中学：学生每天用学案不超过 30 分钟 |
| 课前案用时 | ≤ 20 分钟 | 雅安中学：预习案为浅层次预习，20 分钟能完成 |
| 学生独立完成率 | 预习任务 80% 学生能独立完成 | 学案设计通则 |
| 自学完成度 | 高效自学能完成 70% 内容 | 青岛启迪中学学案条例 |
| 学习目标条数 | 1–3 项 | 青岛启迪中学学案条例 |
| 当堂检测用时 | 5–8 分钟 | 学案板块设计通则 |
| 版面 | 以两页为最佳，学生打开不用翻页 | 导学案设计经验 |
| 行距 | 1.5 倍 | 同上 |
| 页面留白 | 每页留约 1/5 空白供师生备注 | 同上 |

> **留白不是浪费**：经验表述是"就像作画一样，留有'飞白'，才能给观赏者想象的空间"。**没有留白的学案，学生当场无法作答，等于废纸。**

## 1.7 红线

1. **不出现答案与解读结论**——学案一出现答案，学生只等着对答案，课堂讨论立即失效
2. **不出现教学目标（教师视角）、设计意图、预设应对、教师活动**
3. **每个问题之后必须留白**（≥ 2 行或下划线）
4. **不做习题集**——避免"简单化、剪贴化、习题化"；**少用选择填空**，多用简答、解答类问题，把思维过程显性化
5. **不超量**——超出 30 分钟/天的学案，学校层面即视为不合格
6. **不搞一刀切模板**——文言文与写作课型的栏目不同；不确定时按《1.4》分体裁处理
7. **知识小结的具体知识点要留空**，不印现成结论

## 1.8 交付前检查清单

- [ ] 版头信息完整（课题 / 课号 / 课时 / 主备人 / 审核人 / 编号 / 日期）
- [ ] 学习目标为**学生视角**（"能……"），1–3 条，与母本教学目标同源
- [ ] 学习重难点在列
- [ ] 有**学法指导**栏
- [ ] 有**我的疑惑**栏（留白）
- [ ] 有**归纳小结**栏，且具体知识点留空
- [ ] 每处提问之后都有书写空间
- [ ] 无答案、无解读结论、无设计意图、无教师活动
- [ ] 当堂检测 5–8 分钟可完成
- [ ] 分层作业三档明确（必做 / 选做 / 挑战）
- [ ] 有**学习反思**栏
- [ ] 全份用时 ≤ 30 分钟，课前案 ≤ 20 分钟
- [ ] 按体裁增补了对应栏目（文言文有正音与知识点栏、诗歌有诵读标注栏等）
- [ ] 选择填空题占比控制在少数，主体为简答 / 解答类
- [ ] 版面 ≤ 2 页为佳，1.5 倍行距，留白充足

# 第二部分：说课稿

## 2.1 定位

**说课 = 教师口头表述具体课题的教学设想及其理论根据。** 它回答的是"**我为什么这样教**"，而不是"我怎么教"。

**分类（影响内容重心，写前先问清）**：

| 分类标准 | 类型 | 对内容的影响 |
|---|---|---|
| 时间 | 课前说课 / 课后说课 | **课后说课**须加实施效果与反思，说课稿要留出"实际上的怎么样"一节 |
| 用途 | 检查性 / 示范性 / 研究性 / **评价性**说课 | 评价性（比赛、招聘）最重理论依据与逻辑闭环 |

## 2.2 分节：主流"六说"与本流程取值

**主流六说**（各地评分表与教研材料的一致口径）：

> 说教材 · 说学情 · 说教法 · 说学法 · 说教学过程 · 说板书设计

**常见的扩展**（在六说基础上加节）：说教学目标、说重难点、说教具 / 教学准备、说教学评价、说作业设计、说教学设计说明（总结升华）、说教学反思。

**本流程的取值：九节**，理由写在下面：

| 节 | 内容 | 与主流口径的关系 |
|:-:|---|---|
| 一 | **说教材与本课定位**：单元分析（单元位置、人文主题、所属学习任务群、课标要求）+ 课时定位（本课时在单元中的位置与作用）+ 文本特点 | 把主流"说教材"升级为"单元分析 + 课时定位"。**这是 2017 课标以来语文说课最实质的变化**，见 2.3 |
| 二 | 说学情 | 主流 |
| 三 | 说教学目标与重难点，**并说明依据**（任务群 + 学业质量水平 + 核心素养落点） | 主流分开为"说目标 + 说重难点"，此处合并并强制附依据 |
| 四 | 说教法学法与课时安排 | 主流 |
| 五 | **说教学过程**：逐环节写"做什么 — 学生怎么学 — 为什么这样设计"，含主问题与追问链、时间分配 | 主流的重点部分，权重最高（约 40%） |
| 六 | 说板书设计 | 主流 |
| 七 | 说作业设计（三档的区分逻辑） | 扩展 |
| 八 | 说检测与评价（检测任务与量规，以及如何判断学生到了没到） | 扩展，对应教学评价 |
| 九 | 说设计反思与预判（可能的偏误、本稿的取舍与已知不足） | 扩展；**课后说课**时改为"实施效果与反思" |

## 2.3 语文说课的两处新范式（务必遵守）

**一、开头先做"单元分析 + 课时定位"，不直接跳进"教材分析"。**

新教材语文说课的通行写法是：先说本单元出自哪一册、人文主题是什么、**属于哪一个学习任务群**、课标对该任务群的要求是什么，再据此给出单元整体框架；然后说本课时在单元框架中的位置与作用（如"承上启下"）。**去掉"任务群"这一层，语文说课在评委眼里就是旧范式。**

**二、目标要落到核心素养四方面，并落在具体的学习行为上。**

不要写成"培养学生的审美能力"这类不可证的表述；要写成学生在任务中可观察的行为。

## 2.4 篇幅与时间分配（按评分权重倒推）

**先算总字数**：正常语速 180–220 字/分钟。

| 说课时长 | 正文建议字数 |
|---|---|
| 10 分钟 | 1800–2200 字 |
| 15 分钟 | 2700–3300 字 |

**再按权重分配篇幅**。三类来源的评分表口径高度一致：

| 环节 | 分值权重（各地说课评分表） | 10 分钟课例的时间 |
|---|---|---|
| 说教材（含定位 / 目标 / 重难点） | 15%–20% | 基本部分合计约 3 分钟 |
| 说教法学法 | 15%–20% | 同上 |
| 说学情 | 10% | 同上 |
| **说教学过程** | **40%** | **约 6 分钟** |
| 说教学评价 / 反思 | 10% | — |
| 教师基本素质 / 综合素质 | 5%–20% | 机动约 1 分钟 |

**结论：教学过程必须占全稿一半左右篇幅。** 在"教材背景"上铺陈过多，是最常见的失分点。

**两处口径如何对齐（写前先看这一条，可省一轮返工）**：上表的 **40%** 是**评分权重**，结语的「一半左右」是**篇幅的期望上限**——两者说的是同一件事的两个刻度：**教学过程必须是全稿最大的单节**。实操取 **40%–50%** 即可，**不必强行凑到 50%**——其余八节若为凑比例而压缩过度，"说教材"的单元分析与"说学情"的真实疑难会先残缺，反而丢分。给两个可比的实作数：

| 说课时长 | 正文总字数 | 教学过程建议区间 | 「劝学」示例实作 |
|:-:|:-:|:-:|:-:|
| 10 分钟 | 1800–2200 | 720–1100 字 | — |
| 15 分钟 | 2700–3300 | 1100–1650 字 | 正文 3500 字，教学过程 1548 字，**占 44%** |

> **统计口径**（示例已按此计）：字数按**段落正文**计，**不含表格**（表格属可看不可读的辅助件）。若把"说教材"里的目标表一并计入分母，教学过程的占比会被低估，越改越偏。


## 2.5 高分策略（有据）

1. **说主不说次，说异不说同，说精不说粗**——讲究省略、过渡、照应
2. **突出理论，但忌贴标签**——把"教学设计"与其"理论根据"熔于一炉；既不空谈理论，也不"穿靴戴帽"造成教例与理论"油水分离"
3. **逻辑闭环**——教材 → 学情 → 目标 → 教法 → 过程 → 评价，形成完整链条，每处设计都能追到依据（如"因学生已有 X，故选 Y 教法，对应过程里的 Z 环节"）
4. **语言**——陈述性语言与课堂教学语言结合，脱稿；不能以念代说
5. **点明任务群与素养落点**——语文说课的"专业性"主要落在这一处

## 2.6 红线

1. **不是教案复述**——每讲一处"怎么做"，必须同答"为什么这么做"
2. **不写教师活动流水账**——"然后我提问……然后我总结……"是最典型的废稿特征
3. **不空谈理论、不贴标签**——"体现了新课标理念"这类无着落的话不用
4. **不写不可证的判断**——"教学目标明确""重难点突出"等于没说
5. **不平均用力**——教学过程不足一半篇幅的稿子，评分必然吃亏
6. **必点学习任务群与核心素养落点**——语文说课不写这一层，等于缺了新课标的接口
7. **字数与时长匹配**——10 分钟说课写 4000 字，现场必然超时
8. **说课稿 ≠ 课件**——上屏的是框架与关键句，讲稿里才是成段的话

## 2.7 交付前检查清单

- [ ] 开头有**单元分析**（含人文主题与**所属学习任务群**）与**课时定位**
- [ ] 学情分析具体（已有经验 / 真实疑难），不是"学生基础较好"这类套话
- [ ] 目标附**依据**（任务群 + 水平 + 素养落点）
- [ ] 每个教学环节都写了**设计意图**
- [ ] 全稿有**逻辑闭环**：学情 → 教法 → 过程的对应关系说得出来
- [ ] **教学过程占全稿一半左右**篇幅
- [ ] 板书设计说明了"为何这样呈现 / 如何随讲解生成"
- [ ] 作业设计说明了三档的区分逻辑

**一条重要提醒**
