# 四份 Word 交付物规范

第 7 步的执行细则。回答三个问题：**每份文件装什么、不装什么**、**Word 里怎么排**、**四份怎么保证对得上**。

---

## 一、单一事实源与派生关系

**母本 = 教学设计**，全部交付物从它派生。四条铁律：

```
冻结母本（教学设计 · 十二节 + 两附）
    │
    ├──→ 教案.docx       【删】解读过程、量规分档、分层参数论证
    ├──→ 学案.docx       【改】视角：教师 → 学生；【删】答案与设计意图
    ├──→ 说课稿.docx     【改】视角：怎么做 → 为什么这么做
    └──→ 课件 .pptx      【删】目标、意图、预设、答案（课件版红线）
```

1. **母本先冻结**：第 6 步把检测任务与评分量规回填进母本第十二节、过完检查点，母本才冻结。
2. **派生不另写**：教案、学案、说课稿一律从冻结母本裁剪转换，**禁止各自另起一稿**。
3. **同改同废**：母本一改，四份 Word 与课件全部作废、重出。不做"只改其中一份"的局部修补。
4. **转 Word 不加料**：转 .docx 的过程只做体裁适配与版式设计，**不新增教学结论、不改动教学点与数据**。

## 二、四份文件的分节规范

### 2.1 教学设计（母本）

**读者**：教师自用、教研组存档、公开课备案。**最全的一份**，其余三份都是它的子集或改写。

| 节 | 内容 |
|---|---|
| 一 | 依据（第 1 步产出：任务群 / 学业质量水平 / 素养落点） |
| 二 | 教学定位（本篇在单元中的位置、与前后篇目的关系） |
| 三 | 教学目标（3 条，可观测行为动词，分素养维度） |
| 四 | 教学重难点 |
| 五 | 课时安排表（总时长误差为 0） |
| 六 | 情境任务链（一个大情境 + 2–4 个递进子任务） |
| 七 | 主问题设计（全课唯一）+ 追问链 |
| 八 | 板书设计 |
| 九 | 分层作业（基础 / 提高 / 拓展） |
| 十 | 教学预设与应对（2–3 处） |
| 十一 | 检测任务与评分量规（第 6 步回填，含对标水平号与三档证据要求） |
| 十二 | 分层参数（重点校 / 普通校 / 薄弱校差异点） |
| 附一 | 四个卡口自检 |
| 附二 | 教材版本与课标版本核对说明（用哪一版、哪些"待核对"） |

**不装什么**：无。这是唯一不含"禁忌内容"的一份。

### 2.2 教案

**读者**：教师本人上课执行，或同组教师代课。**可执行**是第一要求。

| 节 | 内容 | 要求 |
|---|---|---|
| 一 | 基本信息 | 篇目 / 课型 / 课时 / 学情版本 / 对标水平 |
| 二 | 教学目标 | 与母本**逐字一致** |
| 三 | 教学重点与难点 | 与母本一致 |
| 四 | 课时安排表 | 逐环节四列：**环节 ｜ 时长 ｜ 教师活动 ｜ 学生的活动**（+ 设计意图可并栏） |
| 五 | 主问题与追问链 | 主问题文字与母本完全一致 |
| 六 | 板书设计 | 层级化呈现，随讲解逐步出现的顺序要标出 |
| 七 | 教学预设与应对 | 学生可能答偏 → 追问方向 |
| 八 | 作业布置 | 只写三档任务的要求与完成方式；**题目正文在学案** |
| 九 | 教具与资源 | 课件对应页次、朗读音频、拓展材料清单 |

**"学生的活动"栏是这份文档的命门**：不得为空、不得写"听讲""思考""配合老师"。写不出学生具体做什么、留下什么可见痕迹，说明这个环节还没设计完。

**不装什么**：文本解读的推导过程、评分量规的三档描写、分层参数的论证——这些留在教学设计里。

### 2.3 学案

**读者**：学生。**留白是它的本体**，不是附件。定位是"学生视角的学习方案"，不是教案的学生版、不是习题汇编。分节表依据见 [`xuean-shuoke-spec.md`](xuean-shuoke-spec.md)。

| 栏目 | 内容 | 要求 |
|---|---|---|
| 版头 | 课题 / 课号 / 课时 / 主备人 / 审核人 / 编号 / 日期 | 校本学案的固定格式，便于归档集册 |
| 一 | **学习目标** | 学生视角（"能……"）1–3 条，与母本同源；**不得出现第四条** |
| 二 | **学习重难点** | 学生视角；常被漏掉，必写 |
| 三 | **课前案** | 知识链接（作者 / 背景 / 文体常识）+ 预习任务 + **我的疑惑**（留横线） |
| 四 | **学法指导** | 本课具体的学习方法提示；这是学案区别于习题集的关键 |
| 五 | **课中案** | 情境任务链的每个子任务，每项三栏：**读什么（原文范围与行号）— 想什么（问题）— 写什么（留白）** |
| 六 | **归纳小结** | 知识体系建构，**具体知识点留空由学生填**，不印现成结论 |
| 七 | 当堂检测 | 1–2 题，对应母本第十一节的检测任务（去掉量规描写）；5–8 分钟可完成 |
| 八 | 分层作业 | 三档题目正文，标注必做 / 选做 / 挑战与完成方式 |
| 九 | **学习反思** | "我的收获" / "还没弄懂的是"——各留 2–3 行 |
| 十 | **评价反馈栏** | 小组互检 / 教师批阅（学案要留下被检查的痕迹） |

**分体裁增补栏目（必做）**：文言文加正音正句、文言知识点栏；诗歌加诵读标注（节奏 / 重音 / 停顿）栏；小说加人物—环境—情节关联表；写作课加论点提炼 / 论据分类模板。**一套模板套所有课型是错的**。

**量化约束**：全份用时 ≤ 30 分钟，课前案 ≤ 20 分钟；版面 ≤ 2 页为佳；1.5 倍行距；每页留约 1/5 空白。

**每处提问之后必须留书写空间**（≥ 2 行或下划线）。只列问题不留白，学生当场无法作答，学案就退化成提纲。

**不装什么（红线）**：**教学目标**（教师视角，含素养维度表述）、设计意图、预设与应对、**答案**、解读结论、教师活动。

> 注意区分：**"学习目标"必须有，"教学目标"绝对不能有。** 前者是学生视角的行为描述，后者含教师立场、素养维度与设计意图。把教学目标原样搬上学案是最常见的错。

**其他红线**：不做习题集（避免"剪贴化、习题化"）、少用选择填空（以简答 / 解答类问题呈现思维过程）、不超量。

### 2.4 说课稿

**读者**：同行、评委、教研组。主语是"**我为什么这样教**"，不是"我怎么教"。分节依据见 [`xuean-shuoke-spec.md`](xuean-shuoke-spec.md)。

| 节 | 内容 |
|---|---|
| 一 | **说教材与本课定位**：单元分析（单元位置、人文主题、**所属学习任务群**、课标要求）+ 课时定位（本课时在单元中的作用）+ 文本特点 |
| 二 | 说学情：学生已有经验与真实疑难 |
| 三 | 说教学目标与重难点：并说明依据（任务群 + 水平 + 素养落点） |
| 四 | 说教法学法与课时安排：为什么用这条路而不是另一条 |
| 五 | 说教学过程：逐环节写**做什么 — 学生怎么学 — 为什么这样设计**，含主问题与追问链、时间分配 |
| 六 | 说板书设计：为何这样呈现、如何随讲解生成 |
| 七 | 说作业设计：三档的区分逻辑 |
| 八 | 说检测与评价：检测任务与量规，以及如何判断学生到了没到 |
| 九 | 说设计反思与预判：可能的偏误、本稿的取舍与已知不足 |

**第一节必须带任务群**。新教材语文说课的通行开头是"单元分析 + 课时定位"，要点明本篇属于哪一个学习任务群、课标对其要求是什么。**去掉这一层，在评委眼里就是旧范式。**

**篇幅：按评分权重倒推，不按模板硬凑。**

| 说课时长 | 正文建议字数 |
|---|---|
| 10 分钟 | 1800–2200 字 |
| 15 分钟 | 2700–3300 字 |

（依据：正常语速 180–220 字/分钟。）

篇幅分配依据各地教研部门的说课评分表：说教材 15–20%、说教法学法 15–20%、说学情 10%、**说教学过程 40%**、教学评价 10%。**结论：教学过程必须占全稿一半左右。** 在教材背景上铺陈过多是最常见的失分点。

**不装什么**：教师活动流水账、无设计意图的环节罗列、"本课教学目标明确""重难点突出"这类不可证的空话、无着落的标签式理论（"体现了新课标理念"）。

**若为课后说课**：第九节改为"实施效果与反思"，写实际发生了什么，不是预设。

## 三、Word 版式与落盘规范

### 3.1 版式

- **标题层级最多三级**：文档标题（一级）→ 节标题（二级）→ 子项（三级）。不设第四级；再往下用加粗行内标签。
- **字体**：文档标题黑体二号居中；节标题黑体四号；正文宋体小四（12pt）、行距 1.5 倍；表格内文字五号。
- **版面**：A4；页边距四周统一 2.5cm。**学案可放宽至 2.0cm 以增加书写面积**。
- **页眉**：`《篇目》· 课型 · 课时 · 学情版本`；**页脚**：页码。
- **表格一律用真实表格**，不用 ASCII 框线；跨页时重复表头，避免行被切断。
- **板书在 Word 里改用层级表格承载**（第一行主问题或中心词，逐层向下展开），或"缩进 + `└─` 连接符"的行式表达。**不要贴 ASCII 字符画**——等宽字体在 Word 里易错位，这是本流程最容易出现的排版事故。课件 PPT 仍用原生图形重画板书。
- **检测与量规**用表格（维度 × 三档），每格写可检验的证据要求，不写"理解深刻"。
- **配色克制**：正文黑白为主，全文最多一个强调色用于节标题。**学案不用深色底**（打印耗材与可复印性）。
- **图片**：不插入未经核对的作者照片；确需作者形象时，用课件同一套影像蒸馏图并标注"示意图"。

### 3.2 落盘与命名

- **目录**：与课件同级（如 `<workspace>/output/<篇目>/`）。
- **文件名**：`故都的秋_教学设计.docx` / `_教案.docx` / `_学案.docx` / `_说课稿.docx`。
- **不带书名号、不带空格、不带版本号**（版本信息写页眉，写进文件名会在复制分发的途中失效）。
- 可选扩展（默认不出）：`_检测卷（学生版）.docx`、`_检测卷（教师版·含答案与量规）.docx`。

## 四、生成流程

1. **确认母本已冻结**（第 6 步检查点已过）。
2. **按序逐份生成**：教学设计 → 教案 → 学案 → 说课稿。母本先落地，后面三份便于随时比对。
3. **每份加载 `tencent-docx`**，把该份对应的内容作为创作材料走其 `full_pipeline`（S1 创作 → S2 美化 → S3 转 `.docx`）。
   - **禁止用 `python-docx` 等裸库直接拼 .docx**（违反该技能的强制规则，且拿不到它的版式能力）。
   - **禁止把四份合并成一份多章节文档**——学案里绝不能出现教师版内容。
4. **每份生成后 `present_files` 打开预览**（`tencent-docx` 的硬约束）。
5. **四份齐了跑一致性清单**（下节），不一致以母本为准改四份。

## 五、一致性检查清单（四份互查）

**内容同源**
- [ ] 教学目标文字四份逐字一致（学案可改写为"我能……"，但**条数与所指内容不得增减**）
- [ ] 课时安排的时间数据四份一致，总和 = 课时总时长，误差 0
- [ ] 主问题文字四份完全一致
- [ ] 板书层级结构四份一致（可改呈现方式，不可增减层级）
- [ ] 作业三档的分类与要求四份一致

**红线未越**
- [ ] 学案未出现**教学目标**（教师视角）、设计意图、预设应对、答案与解读结论
- [ ] 学案**学习目标、学习重难点、学法指导、我的疑惑、归纳小结、学习反思**六项齐全（最常被漏掉）
- [ ] 学案按体裁增补了栏目（文言文有正音与知识点栏、诗歌有诵读标注栏），**未用一套模板套所有课型**
- [ ] 学案全份用时 ≤ 30 分钟，课前案 ≤ 20 分钟；主体非选择题
- [ ] 学案每处提问之后都有书写空间
- [ ] 教案"学生的活动"栏无空、无"听讲""配合"这类空话
- [ ] 说课稿**第一节含所属学习任务群**（缺此层即旧范式）
- [ ] 说课稿每个环节都写了设计意图，无教师活动流水账
- [ ] 说课稿**教学过程占全稿约一半篇幅**；字数与说课时长匹配
- [ ] 说课稿无"教学目标明确""重难点突出"这类不可证表述

**版式与落盘**
- [ ] 无 ASCII 字符画板书；板书用层级表格或缩进行式
- [ ] 标题层级不超过三级，全篇样式统一
- [ ] 四份文件名符合规范，页眉含篇目 / 课型 / 课时 / 学情版本
- [ ] 引用的课文原文已核对；未核对的已标"待核对"

**与课件一致**
- [ ] 主问题文字、板书结构、任务顺序与 `.pptx` 一致（课件版另查其自身红线）

## 六、常见坑

| 坑 | 后果 | 正解 |
|---|---|---|
| 四份各写各的 | 目标文字对不上，教研组一眼看出 | 一律从冻结母本派生 |
| 学案做成"教案的学生版"（把答案挖空） | 学生等着对答案，讨论失效 | 学案是学习路线图，留白是本体 |
| 学案用一套模板套所有课型 | 文言文缺正音与知识点栏、诗歌缺诵读标注，学生用不上 | 按体裁增补栏目（见 `xuean-shuoke-spec.md` §1.4） |
| 学案做成习题集、以选择填空为主 | 思维过程看不见，退化为刷题 | 少用选择填空，以简答 / 解答类问题显化思维 |
| 学案超量 | 学校层面直接判不合格 | ≤ 30 分钟/天，课前案 ≤ 20 分钟 |
| 说课稿没写学习任务群 | 在评委眼里是旧课标范式 | 第一节"说教材与本课定位"必须点明任务群 |
| 说课稿在"教材背景"上铺陈过多 | 教学过程不足一半，评分吃亏 | 按评分权重分配篇幅，教学过程约占一半 |
| 说课稿字数与时长不匹配 | 现场必然超时或撑不满 | 10 分钟 ≈ 1800–2200 字 |
| 说课稿写成教案复述 | 评委听到的是"我怎么教" | 说课稿写"我为什么这样教" |
| 教案"学生的活动"栏写"听讲" | 无法判断学生是否真在学 | 追问"学生具体做什么、留下什么痕迹" |
| 母本没冻结就转 Word | 母本一改四份全废 | 先冻结，再派生 |
| 四份合成一份多章节 Word | 学案流出教师版内容 | 分四份独立生成 |
| Word 里贴 ASCII 板书 | 等宽字体错位，版面崩 | 用层级表格承载 |
| 学案印满、无留白 | 学生没法当场写，等于废纸 | 每处提问后留 ≥ 2 行 |
| 转 Word 时"顺手补内容" | 与母本失同步 | 转格式不加料 |
| 文件名带书名号或空格 | 分发、批处理时路径出错 | 用 `篇目_类型.docx` |
