# 《劝学》课件叙事稿（STORY）

> 每页讲什么、怎么过渡。**本稿是课件的讲解脚本，不上屏。** 上屏的只有「页—内容」清单里的那些字。
> 全课只推进一个主问题：**谈「学」却只写自然物象——这样的「劝」，为什么更有说服力？**

---

**P1 标题页** `劝　学 · 荀子`
不讲话，等学生静下来。屏幕上的引语「学不可以已」就是本课的第一句课文，先让学生自己读一眼。

**P2 情境导入** `「青，取之于蓝，而青于蓝」——他是在说靛青吗？`
→ 过渡语（口语，不上屏）：「先只看这一句。他说的当然是靛青——可这是《劝学》，是谈学习的。他为什么拿靛青开头？」
配图 img_1_indigo 安静地占一侧，不解释。**这一页只提问，不给答案。**

**P3 作者介绍页** `他为什么说「学不可以已」？`
只讲两点：荀子认为人性本需后天改造；他在稷下学宫讲学，《劝学》是《荀子》开篇。
→ 过渡语：「所以你们看，他这句话不是劝人『要多读书』这么轻——在他看来，不学，人是要坏下去的。」
配图 img_2_author 为**意象化形象**，页面上标「示意图」，**说明这不是真实肖像**。

**P4 主问题页** 40pt，全篇最大。读完停 5 秒，不解释。
「这个问题今天不急着答。我们分三件事，一件一件把它拆开。」

**P5 任务链总览** 三件事：找喻体 / 找借力 / 找对照。
→ 「这三件事做完，最后要讲给初一的同学听。先提醒一句：讲稿里不许出现『用了比喻，很生动』。」

**P6 五个物象，一个共同点**
只出示青、冰、木、金。不解释。让学生先自己译、自己找。
配图 img_3_wheel 对应「輮以为轮」——**这一页的图对应的是第 8 页的语句，故意先出现，制造悬念**。

**P7 它们都指向一个字** `变`
学生自己归纳出「青于、寒于、中规、直、利」都指向「变」之后，再上这一页。**顺序反了，这一页就变成告知。**
（呼应：P6 的图在这里得到解释。）

**P8 变，靠的是什么** `輮使之然也` / `受绳则直` / `就砺则利` → 外力
→ 过渡语：「都是『变』。可木头自己不会弯，金自己不会利——变，总要有个东西在外面推它。记住这个『外面』，下一段要用。」

**P9 这一段里，哪些是「假于物」？**
出示第二段原文片段，配图 img_4_boat。学生找例子的过程不打断。

**P10 借什么，得了什么** 登高 / 顺风 / 舆马 / 舟楫
→ 让学生自己说出那句总结：「人没变，借的东西变了。」**这句必须由学生说出来，不由老师给。**

**P11「君子生非异也」** 否定天赋差异
→ 追一句（不上屏）：「那第一段的『君子博学而日参省乎己』——『参省乎己』明明是向内反省。到底向外还是向内？」
**这处矛盾不给答案**，留给学生争。

**P12 哪些是正面，哪些是反面？**
出示第三段原文片段，配图 img_5_mountain。学生填「正—反」表。

**P13 三组对照** 骐骥 ↔ 驽马 ｜ 锲而舍之 ↔ 锲而不舍 ｜ 蚓 ↔ 蟹
焦点字点上朱色：**舍 / 一 / 躁**。
→ 「上一段讲怎么借力，这一段讲借不借得着——差别就落在三个字上。」

**P14 由物及人** 积土成山 / 积水成渊 / 积善成德
→ 问一句「这三句的顺序能不能换？」让学生说出「物 → 物 → 人」。**这就是全篇的收束：从自然的道理，说到人的德性。**

**P15 板书页**（原生图形，随讲解逐步出现）
四层：一望而知 → 取象（变）→ 假于物（借力）→ 正反对照 → 由物及人。
→ 让学生**照着板书复述**这节课走过的路。复述得出来，这节课才算落地。

**P16 课堂小结** 回扣主问题，三行以内。
→ 「现在回到 P4 那个问题。谁能用一句话回答？」

**P17 分层作业**（只留任务要求，不留答案）
基础 / 提高 / 拓展三档。提高档就是 P5 说的「讲给初一同学听」的 150 字讲稿。
→ 收尾：不总结，直接下课。
