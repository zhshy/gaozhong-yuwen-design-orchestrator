## 一、学习目标（学生可理解版）

我这节课要做到三件事：

1. 我能说清「青，取之于蓝，而青于蓝」里两个「于」有什么不一样，也能说出「而」在这里起了什么作用。
2. 我能找出第一段里的五个自然物象，说出它们**共同**在讲什么。
3. 我能找出第二段「假于物」的例子和第三段的正反两组例子，说清荀子是怎么把「学不可以已」讲成立的。

## 七、当堂自评

对照第一部分那三件事，逐条自评。**每一条都按下面的标准划勾，不要凭感觉。**

### 第 1 条｜两个「于」和一个「而」

- [ ] **还没做到**：两个「于」都译成一样，或说不出「而」的作用
- [ ] **做到了**：能说出前一个表**来源**、后一个表**比较**；能说出「而」表**转折**
- [ ] **做得好**：还能说出「青于蓝」不是「变青了」，而是「**比来源更青**」——重点在「而」后面

### 第 2 条｜五个物象的共同点

- [ ] **还没做到**：只填了「变成了什么」，说不出共同点
- [ ] **做到了**：能说出它们都在讲「**变**」
- [ ] **做得好**：还能说出「变」都要**靠外力**（輮、绳、砺），并说出这是为第二段做铺垫

### 第 3 条｜借力与对照

- [ ] **还没做到**：只抄了原文，说不出「借什么、得什么」
- [ ] **做到了**：能说出两处「借—得」，并找出两组正反对照
- [ ] **做得好**：能说出四处的共同结构是「**人本身没有变强，是借助的东西变了**」，或说出三组对照都指向「**舍 / 一 / 躁**」

> 自评用的是**可检验的档位描述**，不是"我学会了 / 我没学会"。
