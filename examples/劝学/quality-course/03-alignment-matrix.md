# 03 教学评一致性矩阵

> 第 6 步的审计产物，也是 **门禁四（本模式最高优先级门禁）** 的判据。
> 判据：主链 `目标 → 教学点 → 活动 → 证据 → 评价` **必须闭环，缺任一节即阻断**。

**填表说明（三处要讲清）**：

1. **`目标三` 占两行**——它由两个教学点（`教学点二` 借力、`教学点三` 对照）共同支撑。这是**如实反映**，不是重复计数：两条链各自可查。

## 三、派生链（每个交付件的元素都要能指回主链）

```
                          ┌─→ 检测任务一（任务单）→ 承载 活动一
                          ├─→ 作业一 / 作业二 / 作业三（作业）→ 回指 目标一、二、三
目标 → 教学点 → 活动 → 证据 → 评价 ├─→ P5–P14（课件页）→ 支撑各 活动
                          └─→ 微课环节一～七（微课分镜）→ 呈现各 活动
```

**判据**：**每个交付件里的每个元素，都要能指回主链的某一节；指不回去的，删掉。**

**本例逐件对照**：

| 交付件 | 元素数 | 能否全部指回 | 说明 |
|---|:-:|:-:|---|
| 学习任务单 | 3 个任务 | ✅ | `检测任务一→目标一、二`、`检测任务二→目标三`、`检测任务三→目标三` |
| 作业练习 | 3 道题 | ✅ | `作业一→目标一`、`作业二→目标二`、`作业三→目标三` |
| 课件 | 17 页 | ✅ | 页—链对应见 `07-ppt-plan.md` |
| 微课运行稿 | 7 段 | ✅ | 段—链对应见 `08-video-runtime.md` |

## 五、`视频门禁二` 专项自查（精品课最需要防的一种失败）

**这是本领域评审最容易失分、也最容易被本技能拦下的一类问题。**

**要防的具体形态**：

```
教学设计写着：学生比较三处比喻，圈画本体/喻体，自己得出结论
视频里却是：教师说"这三处比喻都说明了学习的重要性"
```

**本例的逐段自查**：

| 段 | 教学设计说学生做什么 | 视频里谁在做 | 结论 |
|:-:|---|---|:-:|
| `微课环节一` | 齐读该句并写下第一反应 | 学生（写） | 通过 |
| `微课环节二` | 逐处圈画、填表、圈两处「于」 | 学生（圈画填写） | 通过 |
| `微课环节三` | 说出「輮/绳/砺」＝外力，写进表内 | 学生（说 ＋ 写） | 通过 |
| `微课环节四` | 找例子、填「借—得」表 | 学生（填写） | 通过 |
| `微课环节五` | 说出「人没变，借的东西变了」 | 学生（说 ＋ 写） | 通过 |
| `微课环节六` | 填「正—反」表、指出焦点字 | 学生（填写） | 通过 |
| `微课环节七` | 用三张表写一句话作答 | 学生（写） | 通过 |

**唯一需要说明的一处**：`微课环节五` 里教师有 20 秒的**结构化提示**（"四处例子有没有共同的样子？"）。这是**追问**，不是**代答**——最终那句话由学生说出并写进表内。**判据**：教师说的是**问题**还是**答案**。本例是问题。

**处理原则（照此执行）**：

> 时长不足时，正确做法是**砍掉一个任务的呈现**（把该段整体从微课里去掉，课堂上仍做），
> **不是**让教师替学生说完。用"视频时长有限"当理由是**不接受**的。
