> 第 6 步的审计产物，也是 **JPK-04（本模式最高优先级门禁）** 的判据。
> 判据：主链 `OBJ → TP → ACT → EVID → AS` **必须闭环，缺任一节即 BLOCK**。

**填表说明（三处要讲清）**：

1. **`OBJ-03` 占两行**——它由两个教学点（`TP-02` 借力、`TP-03` 对照）共同支撑。这是**如实反映**，不是重复计数：两条链各自可查。
2. **`OBJ-01` 与 `OBJ-02` 共用 `ACT-01`、`OUT-01`、`E-01`**——同一个活动同时承载"辨虚词"与"判取象"两面，因此挂两个目标。**允许**，但要求该活动的 `E-01` 里**两个目标的证据都能分辨**（`E-01` 的"两列 ＋ 旁注"正是为此拆的）。
3. **`ACT-04`、`OUT-04`、`E-04` 未进矩阵**——它们是**收束性作答**，是 `AS-03` 的作答载体，不单独服务某一个目标。它们挂在检测任务 3 下，见 `04-teaching-design.md` 第十一节。

**每一列都不空**：十列全部有值，说明没有一件交付物与设计脱节。

## 三、派生链（每个交付件的元素都要能指回主链）

```
                          ┌─→ TASK-01（任务单）→ 承载 ACT-01
                          ├─→ HW-01 / HW-02 / HW-03（作业）→ 回指 OBJ-01/02/03
OBJ → TP → ACT → EVID → AS ├─→ P5–P14（课件页）→ 支撑各 ACT
                          └─→ SEG-01…07（微课分镜）→ 呈现各 ACT
```

**判据**：**每个交付件里的每个元素，都要能指回主链的某一节；指不回去的，删掉。**

**本例逐件对照**：

| 交付件 | 元素数 | 能否全部指回 | 说明 |

## 五、`JPK-VIDEO-002` 专项自查（精品课最需要防的一种失败）

**这是本领域评审最容易失分、也最容易被本技能拦下的一类问题。**

**要防的具体形态**：

```
教学设计写着：学生比较三处比喻，圈画本体/喻体，自己得出结论
视频里却是：教师说"这三处比喻都说明了学习的重要性"
```

**本例的逐段自查**：

| 段 | 教学设计说学生做什么 | 视频里谁在做 | 结论 |
|:-:|---|---|:-:|
| `SEG-01` | 齐读该句并写下第一反应 | 学生（写） | PASS |
| `SEG-02` | 逐处圈画、填表、圈两处「于」 | 学生（圈画填写） | PASS |
| `SEG-03` | 说出「輮/绳/砺」＝外力，写进表内 | 学生（说 ＋ 写） | PASS |
| `SEG-04` | 找例子、填「借—得」表 | 学生（填写） | PASS |
| `SEG-05` | 说出「人没变，借的东西变了」 | 学生（说 ＋ 写） | PASS |
| `SEG-06` | 填「正—反」表、指出焦点字 | 学生（填写） | PASS |
| `SEG-07` | 用三张表写一句话作答 | 学生（写） | PASS |

**唯一需要说明的一处**：`SEG-05` 里教师有 20 秒的**结构化提示**（"四处例子有没有共同的样子？"）。这是**追问**，不是**代答**——最终那句话由学生说出并写进表内。**判据**：教师说的是**问题**还是**答案**。本例是问题。

**处理原则（照此执行）**：

> 时长不足时，正确做法是**砍掉一个任务的呈现**（把该段整体从微课里去掉，课堂上仍做），
> **不是**让教师替学生说完。用"视频时长有限"当理由是**不接受**的。
