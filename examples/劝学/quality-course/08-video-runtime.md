# 08 微课运行稿（提交件 ⑤）

> **本技能产出运行稿，不产出成片。**
> **不规定**视频时长参数、分辨率、码率、片头片尾、字幕、体积、命名、上传限制——这些属"制作规范"，见 `2026-rules.md` §5。
> **不生成 `.mp4`。**

---

## 一、先解决那个矛盾：课堂时间表与微课时间表

**两者并存，互为约束。**

| | 教学设计（提交件 ①） | 本运行稿（提交件 ⑤） |
|---|---|---|
| 按什么时长设计 | **完整一节课**（3 课时 / 135 分钟） | **微课时长** |
| 时间表 | **七列时间项**，Σ ＝ 135 分钟 | **微课环节时间轴** |
| 为什么 | "教学设计"本身是提交件，且官方要求"突出课堂实效"——**压成三段的课撑不起这一项** | 微课是独立呈现形式，有自己的节奏 |

**微课时间轴不是把课堂环节除以 3。**

```
❌ 错误做法：课堂 45 分钟 → 微课 15 分钟 → "每个环节 × 1/3"
✅ 正确做法：按微课的六拍节奏重排（§三）——只保留核心问题、核心任务、核心证据、迁移出口，其余舍去
```

**硬约束（红线 21 / 门禁九）**：

```
微课环节 中的学生任务集合  ⊆  课堂设计的学生活动集合
```

- 视频里出现的每一个学生任务，**必须**在课堂设计里已经存在（编号对应）。
- **视频里冒出课堂设计中不存在的新任务 → 阻断。**
- **反向不算违规**：课堂里有、视频里没有的学生活动，正常。本例课堂有 4 个活动（`活动一～四`），微课只呈现其中 3 个 ＋ 收束作答。

> **`时长` 的取值口径**：本技能**不规定**时长，由用户或本地通知给定。
> **本例未提供本地通知**，故 `时长` 三项标 **`待核验`**；下面微课环节时间轴按 **12 分钟**排布，**仅用于演示节奏结构**，录制前须以通知正文与用户要求核对并重排。

## 二、`微课运行稿`

```yaml
微课运行稿:
  时长:
    目标: "12:00"        # 演示值，待核验
    最短: 空              # 待通知给定
    最长: 空              # 待通知给定
  环节序列: [微课环节一 ... 微课环节七]   # 见 §三
```

**结构字段（逐段）**：`编号` / `时刻` / `目标编号` / `教学点编号` / `教师` / `学生` / `画面` / `技术` / `证据`。

## 三、微课环节分镜表

### `微课环节一`｜问题建立　`00:00–01:10`（70 秒）

| 字段 | 内容 |
|---|---|
| `目标编号` | `目标二` |
| `教学点编号` | `教学点一` |
| `教师.动作` | 出示「青，取之于蓝，而青于蓝」，只问不答 |
| `教师.讲稿` | 「先只看这一句。他说的当然是靛青——可这是《劝学》，是谈学习的。他为什么拿靛青开头？」 |
| `学生.动作` | **齐读该句，并在任务单 `检测任务一` ①栏写下第一反应**（一句话） |
| `学生.预期产出` | 一句话的初始判断 |
| `画面` | 全屏 **P2**（不叠教师画面） |
| `技术` | `启用: 否` |
| `证据` | 任务单 `检测任务一` ①栏的一句话 |

### `微课环节二`｜关键阅读／关键证据　`01:10–03:20`（130 秒）

| 字段 | 内容 |
|---|---|
| `目标编号` | `目标二` |
| `教学点编号` | `教学点一` |
| `教师.动作` | 逐处出示青、冰、木、金，请学生自己指出各自"变成了什么" |
| `教师.讲稿` | 「一处一处来。靛青是从蓼蓝里取的——变了吗？冰是水做的——变了吗？木头呢？」 |
| `学生.动作` | **圈画并填「物象—变化」表；并在「青，取之于蓝，而青于蓝」一句下圈出两处「于」，各写一个词注义** |
| `学生.预期产出` | 表内两列填写 ＋ 两处圈画与旁注 |
| `画面` | 全屏 **P6**（物象页）→ 切 **P7**（"它们都指向一个字：变"） |
| `技术` | `启用: 否` |
| `证据` | 「物象—变化」表 ＋ 圈画痕迹（即 `证据一`） |

> **P7 的顺序纪律**：`P7` 必须在学生自己归纳出"变"**之后**才出。顺序反了，这一页就从"印证"变成了"告知"。

### `微课环节三`｜学习任务 ＋ 即时反馈　`03:20–04:30`（70 秒）

| 字段 | 内容 |
|---|---|
| `目标编号` | `目标二` |
| `教学点编号` | `教学点一` |
| `教师.动作` | 追问"变靠什么"，给出即时反馈口径 |
| `教师.讲稿` | 「都是『变』。可木头自己不会弯，金自己不会利——变，总要有个东西在外面推它。这个『外面』是什么？填进你的表里。」 |
| `学生.动作` | **说出「輮 / 绳 / 砺」＝外力，并写进表内「靠什么变」列** |
| `学生.预期产出` | 表内第三列填写 |
| `画面` | 全屏 **P8**（`輮使之然也 / 受绳则直 / 就砺则利`） |
| `技术` | `启用: 否` |
| `证据` | 表内「靠什么变」列（即 `证据一` 的第三列） |

### `微课环节四`｜学习任务　`04:30–06:40`（130 秒）

| 字段 | 内容 |
|---|---|
| `目标编号` | `目标三` |
| `教学点编号` | `教学点二` |
| `教师.动作` | 出示第二段，请学生找「假于物」的例子 |
| `教师.讲稿` | 「这一段里，哪些是『假于物』？找出两处，说清借的是什么、借来之后得到了什么。」（**不提示答案**） |
| `学生.动作` | **填写「借—得」对照表（找两处）** |
| `学生.预期产出` | 表内两行 |
| `画面` | 全屏 **P9** → 切 **P10**（`借什么，得了什么`） |
| `技术` | `启用: 否` |
| `证据` | 「借—得」表（即 `证据二`） |

### `微课环节五`｜核心突破　`06:40–08:00`（80 秒）

| 字段 | 内容 |
|---|---|
| `目标编号` | `目标三` |
| `教学点编号` | `教学点二` |
| `教师.动作` | **结构化提示（不是代答）**：问"四处例子有没有共同的样子？" |
| `教师.讲稿` | 「登高、顺风、舆马、舟楫——这四处有没有一个共同的样子？**注意：人是变强了吗？**」 |
| `学生.动作` | **说出「人没变，借的东西变了」，并写进表内** |
| `学生.预期产出` | 一句话（写在表下空白处） |
| `画面` | 全屏 **P10** → 切 **P11**（`「君子生非异也」`） |
| `技术` | `启用: 否` |
| `证据` | 表下那句话（即 `证据二` 的结论行） |

> ⚠️ **本段是 `视频门禁二` 的重点观察对象**。教师说的是**问题**（"人是变强了吗？"），不是**答案**；最终那句话由**学生说出并写下来**。**判据：教师说的是问题还是答案。**

### `微课环节六`｜学习任务　`08:00–10:10`（130 秒）

| 字段 | 内容 |
|---|---|
| `目标编号` | `目标三` |
| `教学点编号` | `教学点三` |
| `教师.动作` | 出示第三段，请学生分清正面与反面 |
| `教师.讲稿` | 「哪些是正面，哪些是反面？**为什么偏要把好的和坏的放在一起说？**」 |
| `学生.动作` | **填写「正—反」表；圈出最关键的字** |
| `学生.预期产出` | 表内三行 ＋ 三个焦点字 |
| `画面` | 全屏 **P12** → 切 **P13**（三组对照，焦点字朱色：`舍 / 一 / 躁`） |
| `技术` | `启用: 否` |
| `证据` | 「正—反」表 ＋ 三个焦点字（即 `证据三`） |

### `微课环节七`｜迁移／检测收束　`10:10–12:00`（110 秒）

| 字段 | 内容 |
|---|---|
| `目标编号` | `目标二` ＋ `目标三`（综合） |
| `教学点编号` | `教学点一` / `教学点二` / `教学点三` 综合 |
| `教师.动作` | 回扣主问题；给出出口 |
| `教师.讲稿` | 「现在回到 P4 那个问题：谈『学』却只写自然物象——这样的『劝』，为什么更有说服力？**用你手上那三张表，写一句话回答。至少要引原文一处。**」 |
| `学生.动作` | **用三张表写一句话作答（≥ 1 处原文）** |
| `学生.预期产出` | 一句话书面作答 |
| `画面` | 全屏 **P15**（板书页）→ **P16**（小结）→ **P17**（作业要求） |
| `技术` | `启用: 否` |
| `证据` | 一句话作答（即 `证据四`） |

> **出口与作业同源**：本段的出口 ＝ 学习任务单第八节 ＝ 作业 `作业二`。**三处说的是同一件事。**

## 四、节奏自查（六拍）

| 拍 | 段 | 是否落实 |
|:-:|---|:-:|
| 1 问题建立 | `微课环节一` | ✅ 用"他为什么拿靛青开头"，不是"今天我们来学习…" |
| 2 关键阅读／关键证据 | `微课环节二` | ✅ 前 1 分 10 秒内已进入文本 |
| 3 学习任务 | `微课环节二`／`微课环节四`／`微课环节六` | ✅ 三个任务，每个都有学生动作 |
| 4 即时反馈 | `微课环节三` | ✅ 给出"填进表里"的口径 |
| 5 核心突破 | `微课环节五` | ✅ 落在"人没变，借的东西变了"一处 |
| 6 迁移／检测 | `微课环节七` | ✅ 一个出口，回指核心问题 |

**只保留了**：**1 个核心问题**（P4 主问题）＋ **3 个学习任务**（`检测任务一、二、三`）＋ **1 个核心评价证据**（`证据四`）＋ **1 个迁移出口**（`作业二` 同源）。

**四件"砍掉"清单的执行记录**（相对完整课堂）：

| 砍掉 | 内容 | 课堂上是否仍做 |
|:-:|---|:-:|
| 第 1 件 | 过渡语与寒暄 | — |
| 第 2 件 | 第二、三课时的**部分环节**（如《师说》比较的铺垫） | ✅ 仍在课堂做（`作业三` 相关） |
| 第 3 件 | 拓展背景（荀子生平详述、稷下学宫） | ✅ 简化为 P3 的两句话 |
| 第 4 件 | **学生活动：未砍** | — |

> ⚠️ **第 4 件未砍是本设计的关键判断**。时长如需再压，**正确做法是把某个微课环节整体从微课里去掉**（课堂上仍做），**不是**让教师替学生说完。用"视频时长有限"当理由**不接受**（`视频门禁二`）。

## 五、`微课环节 ⊆ 课堂` 逐段比对（红线 21 硬约束）

| 段 | 视频里的学生任务 | 课堂设计中是否存在 | 结论 |
|:-:|---|---|:-:|
| `微课环节一` | 齐读该句 ＋ 写下第一反应 | ✅ 第 1 课时（齐读；先写后说） | 通过 |
| `微课环节二` | 圈画五处物象、填表、圈两处「于」 | ✅ `活动一` | 通过 |
| `微课环节三` | 说出「輮/绳/砺」并写进表 | ✅ `活动一` | 通过 |
| `微课环节四` | 找「假于物」例子、填表 | ✅ `活动二` | 通过 |
| `微课环节五` | 说出"人没变，借的东西变了"并写下 | ✅ `活动二` | 通过 |
| `微课环节六` | 填「正—反」表、圈焦点字 | ✅ `活动三` | 通过 |
| `微课环节七` | 写一句话作答 | ✅ `活动四` | 通过 |

**结论：`微课环节学生任务 ⊆ 课堂学生活动`，无新任务。**

## 六、产出边界（本次明确）

**本模式产出**：运行稿（分镜表）／时间轴（微课环节序列）／画面设计（PPT 页次、板书、全屏与教师窗口关系）／教师语言（可直接照读）／学生任务（动作与产出）。

**本模式不产出、不规定**：

| 不做 | 理由 |
|---|---|
| 视频时长与格式参数 | 属制作规范 |
| 分辨率／码率 | 同上 |
| 片头片尾模板 | 同上 |
| 字幕规范 | 同上 |
| 文件体积与命名 | 同上 |
| 上传限制 | 同上 |
| **生成 MP4** | **本技能不声称生成视频文件** |

**交付话术（照此说）**：

> "我出的是**运行稿**——每一段讲什么、学生做什么、画面是什么、教师说什么，都写到位了。**录制、剪辑、成片参数**这些不在这份运行稿里，请交给录制环节。"

## 七、逐段技术核查

**全片 7 段，`技术.启用` 均为 `否`**——本微课**不使用任何技术手段**（除画面本身）。

**为什么**：按 `technology-fit.md` 第 5 问，本课的教学难点（学生停在修辞层）**靠逐处圈画与填表即可解决**，技术不带来不可替代的行为变化。技术适切的结论已记为 `技术价值 = 有帮助`（仅指课件投影），**微课段内不需要额外技术**。

> **这不是"技术不足"，是判断。** 本技能**禁止**出现"精品课必须使用 AI／必须数字化"的要求。
