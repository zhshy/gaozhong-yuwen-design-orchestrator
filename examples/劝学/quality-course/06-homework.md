## 一、三道题

### `作业一`｜三处通假字

| 字段 | 内容 |
|---|---|
| `编号` | `作业一` |
| `目标编号` | **`目标一`** |
| `类型` | `巩固`（巩固） |
| `任务` | 找出文中三处通假字——「虽有槁暴」的「有」、「则知明而行无过矣」的「知」、「君子生非异也」的「生」——连同所在整句抄写一遍，并在每处旁注出它通哪个字、在本句中是什么意思 |
| `学生产出` | 三句抄写 ＋ 三处旁注 |
| `证据` | 旁注内容（通哪个字 ＋ 本句何义） |
| `量规` | 三处均需给出「通某字」与「本句义」两项；缺任一项该处不计；三处全对为达标 |
| 格式档 | 基础（必做） |
| 预计用时 | 约 10 分钟 |

**为什么留这道题**：`目标一` 是"语言建构与运用"，落地证据是**在语境中辨字**。通假字是本篇三处高频读错点，且**课堂第 3 课时已讲过**（②课堂承接成立）。

### `作业二`｜讲给初一同学听

| 字段 | 内容 |
|---|---|
| `编号` | `作业二` |
| `目标编号` | **`目标二`** |
| `类型` | `迁移`（迁移） |
| `任务` | 学校「诸子说理」读书角要办一期讲给初一同学的《劝学》分享。请写一段 **150 字左右**的讲稿，说清荀子是怎么把「学不可以已」讲成立的。**必须举出文中至少两处比喻**，并说明这两处分别在讲「变」还是「借力」；不得只写「用了比喻，很生动」 |
| `学生产出` | 150 字讲稿 |
| `证据` | 讲稿中引用的两处比喻 ＋ 对「变 / 借力」的判断 |
| `量规` | 见 §二 `评价三` 三档 |
| 格式档 | 提高（选做） |
| 预计用时 | 约 20 分钟 |

**为什么留这道题**：`目标二` 要求"说明改写会失去什么"，**最直接的证据就是学生自己写一段"讲得让人信"的话**。这是把课堂上的取象判断**迁移到真实表达任务**。

> **与学习任务单第八节同源**：任务单的"课后迁移任务"就是本题。**三处（任务单第八节 / 本题 / 微课 `微课环节七` 末段）说的是同一件事**，不是三份不同的迁移。

### `作业三`｜《劝学》与《师说》比较

| 字段 | 内容 |
|---|---|
| `编号` | `作业三` |
| `目标编号` | **`目标三`** |
| `类型` | `应用`（应用） |
| `任务` | 同单元《师说》开篇是「古之学者必有师」。请比较：《劝学》劝的是「学」，韩愈劝的是「师」——两篇文章对「人怎样才能进步」的回答有什么不同？各引 **两处原文**，写 **300 字** |
| `学生产出` | 300 字比较短文 |
| `证据` | 两篇各两处引文 ＋ 对"不同"的说明 |
| `量规` | 引文准确（四处）；能指出**两篇回答的不同**（不是各说一遍）；只罗列相同点不计为达标 |
| 格式档 | 拓展（学有余力） |
| 预计用时 | 约 25 分钟 |

**为什么留这道题**：`目标三` 是"能说出论证如何成立"。**判断学生是否真的掌握，最好的方式是让他把它放到另一篇上比一比**——这就是"应用"型。

**对标水平三**：「能比较多个文本或材料，多角度、多方面获得信息，从中发现**新的关联**」；「能比较多个不同作品的**异同**」。

## 二、评价标准（`量规`）

### `评价一`｜对应 `作业一`

| 档 | 表现描述（含证据要求） |
|---|---|
| 未达标 | 三处中有两处以上说不出「通某字」，或把「生」直接译作「出生」 |
| 达标 | 三处均能说出「通某字」（有—又、知—智、生—性），并能说出该字在本句中的意思 |
| 优秀 | 三处全对，且能**自己补充**：指出「虽有槁暴」的「暴」读 `pù`、「参省」的「参」读 `cān` 一类同段的读音或字形要点 |

### `评价二`｜对应 `作业三`

| 档 | 表现描述（含证据要求） |
|---|---|
| 未达标 | 只各说一遍两篇的内容，没有"比较"；或引文不足两处 |
| 达标 | 能引出两篇各两处原文，并说出《劝学》讲"学"的路径（积累、坚持、借力）与《师说》讲"师"的路径（从师、师道）在**着力点上不同** |
| 优秀 | 能**发现新的关联**：指出两篇虽都谈"人如何进步"，但《劝学》把进步归因于**方法与积累**（不依赖特定他人），《师说》把进步归因于**他人的传授**（依赖师），因而两文对"要不要靠别人"给出了不同回答 |

### `评价三`｜对应 `作业二`（与检测任务 3 量规同源）

| 档 | 表现描述（含证据要求） |
|---|---|
| 未达标 | 只答「用了比喻，很生动」或「说明了学习的重要性」；未引原文或只引一处 |
| 达标 | 能引**至少两处**比喻，说出它们与「学」的相似点（改变／积累／借力中的任两项），并说出比喻比直说更容易让人接受 |
| 优秀 | 能**对文本的形式提出疑问或作出评价**：指出这些喻体都是**人人验过的自然事实**（靛青确比蓼蓝青、冰确比水寒），用「不证自明」的事去支撑「需要论证」的事，把说服力建立在读者自己的经验上；**或**能指出第三段的反面例子（不积、舍之、蟹）承担了同样的论证功能并给出依据 |

## 四、两处必须说清的写法问题

**一、`类型` 与"三档"不是一回事。**

| | 含义 |
|---|---|
| `类型` | **功能**：巩固 / 迁移 / 应用 |
| 三档 | **难度格式**：基础 / 提高 / 拓展 |

**不要对号**（"基础＝巩固、提高＝迁移"是错的）：巩固题也可以很难，迁移题也可以很浅。本示例的三道题恰好在两个维度上都是递进的，**但那只是巧合，不是规则**。

**二、量规是评价工具，不是评语。**

| 不可用 | 可用 |
|---|---|
| 「理解深刻」 | 「指出三处比喻各自的本体与喻体，且能说明相似点不在『都是常见事物』而在『都是人人验证过的自然事实』」 |
| 「语言优美」 | 「所用比喻与所支持的观点之间有明确相似性，且读者不需解释即可看出关联」 |

## 五、作业量说明

**总量**：`作业一` 约 10 分钟（必做）＋ `作业二` 约 20 分钟（选做）＋ `作业三` 约 25 分钟（学有余力）。

**课情卡中「作业时长上限」为 `未提供`**——本稿按 **≤ 30 分钟**设计（必做 ＋ 选做），**如学校另有规定请改**。

> **作业量不按"题数"衡量，按"是否承接课堂"衡量。** 题多不等于学得多；一道回指清晰、承接课堂的题优于三档齐全但一半是凑数的题。
