# 示例：《劝学》全流程七步产出

这是本技能的一次**真实跑通记录**（2026-09-16），输入参数与七步产出原样保留，供对照检查产出形态。

本示例是**现行规范**下跑出的样本：七步流程、四份 Word 交付、20 页封顶的课件版 PPT、配图走影像蒸馏。

---

## 一、输入（第 0 步）

| 项 | 取值 |
|---|---|
| 篇目 | 《劝学》（节选）· 荀子（统编版高中语文 必修上册 第六单元「学习之道」） |
| 课型 | 单篇精读（文言说理散文） |
| 课时 | **3 课时（135 分钟）** |
| 学情 | **重点校**为主版本（普通校／薄弱校分层参数见教学设计第十二节） |
| 课标 | 《普通高中语文课程标准（2017 年版 2025 年修订）》——学业质量**三级**水平 |
| 交付 | 四份 Word（教学设计／教案／学案／说课稿）＋ 课件 PPT |

> **两处待核对**（已在母本「交付信息」栏注明）：
> ① 必修上册 2025 年秋季起的篇目修订（涉第一、二、三单元与古诗词诵读）**未涉及第六单元**，但请以学校实际用书核对原文。
> ② 「輮以为轮」一句的字形各印次有差异（部分印次作「𫐓」），本稿按通行本作「輮」，**教学时以学生用书为准**。

## 四、课件的视觉方案（供复用）

| 要素 | 取值 | 用途 |
|---|---|---|
| 底色 | `#F4F1E9` | 素简米，全篇铺底（先秦简牍的纸面色，与配图纸面同调） |
| 主字色 | `#1C1A17` | 墨，标题与正文 |
| 辅字色 | `#4B463F` | 褐墨，说明性文字、页脚 |
| 点睛色 | `#9C2E22` | 朱砂，**只用在焦点**：主问题页的「更有说服力」、巨字「变」、巨字「外力」、「生非异」、三组对照的焦点字（舍／躁／一）、板书收束行 |
| 字体 | 楷体（标题／课文原句／巨型字）＋ 微软雅黑（正文／追问） | 选 Windows 必然可用的字体，避开思源系在教室机器上缺失的风险 |

**版式**：非对称；三区母版（标题区 100 / 内容区 540 / 页脚 40）自第 2 页起一致；相邻页不出现重复版式；留白刻意做成起伏（P2、P4、P16 大留白 40%+）。

**字号换算口径**（本稿实作，已在 `DESIGN.md` 声明）：页面按 1280×720 px 排版，**1pt ≈ 1.333px**。故实作取值为——正文 **28px**（≈21pt）、标题 **40px**（≈30pt，全篇统一）、主问题 **56px**（≈42pt）、引文 32px、**页脚与最小字 24px（≈18pt，即绝对下限）**，全篇无小于 24px 的字。

**配图落盘规格**：`ImageGen` 原始产出为 1536×1024 无损 PNG（约 2.2 MB/张），而页面最大显示尺寸仅 548×436 px。统一压到 **1400×933 / JPEG q90**（约 0.2–0.3 MB/张），课件总体积由 **11.4 MB 降到 1.33 MB**，页面无可见损失（仍有 2.5 倍超采样）。

## 五、三点必须说清的事

**1. 课件是「课件版」，里面没有教学设计——这是设计要求，不是缺件。**

按课件版红线，**禁止出现**教学目标、设计意图、预设应对、教师自述、作业答案。这些内容全部在 `劝学_教学设计与检测量规.md` 与四份 Word 里。

**2. 课件里没有一页是「教学目标」。** 若课堂上习惯先亮目标，需显式说明，否则按红线默认不加。

**3. 课件最长的两页是原文片段页，不是违规。**

「每页正文 ≤ 30 字」这条硬线，按 `chinese-lesson-design` 的原文**不含引用的文本片段与板书页**。P9（第二段原文）、P12（第三段原文）、P15（板书）正属豁免范围——文本片段必须给原文并标明出处，方便学生翻书定位。
