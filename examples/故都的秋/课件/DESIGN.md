# DESIGN.md —《故都的秋》课件

## 0. 风格路由结论

场景为**高中语文课件（投屏给学生）**。对照 `design-principle.md` §风格场景适配表：教育类课件在预设分支中限定为「教学课件（理工医）」，语文学科不属该分支；亦不属商务咨询、红金政务。→ **全表无命中，走通用设计原则（universal-only）**，仅引用本文件与 `STORY.md` 原创设计稿。

色彩取自通用法则 §2 参考表的「人文 / 哲学 / 文化」一行——宣纸米底 + 松烟墨字 + 朱砂点睛，这与课文的水墨质感、以及"投屏要干净不花哨"的硬要求同时成立。

## 1. 画布与母版（三区，全篇固定）

- 画布：1280 × 720
- Slide padding：`20px 64px`（安全区，禁止绝对定位绕过）
- **A · 标题块**：`y 20–120`，高 **100px**。页面主标题 34px bold，左对齐；标题块右侧**不放任何装饰小图**。
- **B · 内容区**：`y 120–660`，高 **540px**。一切正文、原句、图、图示。
- **C · 页脚条**：`y 660–700`，高 **40px**。左侧统一角标（朱砂方印 + 单元名），右侧页码 `NN / 15`，14px。
- 封面（P1）为全幅图自定义版式，省略 A/B/C 分区，但不省略安全区。
- P3 / P12 / P14 为居中大字页，A 区保留空标题位以维持母版一致（不写文字，仅留位置）。

## 2. 颜色系统（4 个 hex，全篇唯一）

| 角色 | 值 | 用途 |
|:-|:-|:-|
| 背景 | `#F7F4EC` 宣纸米 | 全篇页面底色 |
| 主色 | `#1A1A1A` 松烟墨 | 标题、原句正文、板书线条 |
| 辅色 | `#3F4A55` 青墨 | 说明文字、页脚、分隔线、图示次级色 |
| 强调色 | `#A8351A` 朱砂 | **只出现在焦点元素**：主问题关键词、两个「没有」、巨型数字「4」、角标方印、页码点 |

派生用色仅允许以下半透明形式，不计为新 hex：
- 卡片底：`rgba(63,74,85,0.06)`（青墨 6%）
- 卡片描边：`rgba(26,26,26,0.10)`
- 图版蒙版：`rgba(26,26,26,0.42)`（压在照片上承载白字）
- 浅遮罩：`rgba(255,255,255,0.55)`

### 2.1 色彩面积分配

| 页面类型 | 主色 | 辅色 | 强调色 | 中性 |
|:-|:-|:-|:-|:-|
| Hero 页（P1/P3/P10/P12） | ≤ 55% | ≤ 20% | **15–20%** | 剩余 |
| Supporting 页 | ≤ 50% | ≤ 25% | **≤ 5%** | 剩余 |

节奏差异：P1、P3 为高留白浅底（强调色仅朱砂方印与主问题关键词）；P5、P7 因 L1 大图占据半屏，主色（墨）面积显著高于其余页；P10 的巨型「4」用强调色铺满，是全篇强调色占比最高页。→ 至少 3 页色彩比例与其他页显著不同，满足"禁止每页雷同"。

### 2.2 渐变与半透明

- 仅一处渐变：封面底部文字压条 `linear-gradient(90deg, rgba(26,26,26,0.72) 0%, rgba(26,26,26,0.12) 100%)`，保证白字可读。
- 卡片一律 `boxShadow: '0 2px 12px rgba(26,26,26,0.06)'`，不用浮夸投影。
- 元素重叠时底层 `opacity: 0.15–0.3`（用于板书图的次级轴线）。

## 3. 字体系统（2 套家族）

| 层级 | 字体 | 字号 | 字重 | 行高 | 用途 |
|:-|:-|:-|:-|:-|:-|
| 封面主标题 | KaiTi | 80px | bold | 1.15 | 仅 P1 |
| 巨型锚点 | KaiTi | 96px | bold | 1.0 | P3 主问题关键词、P10 的「4」 |
| 章节大字/收束金句 | KaiTi | 64–68px | bold | 1.3 | P12、P14 |
| 页面主标题（A 区） | KaiTi | 34px | bold | 1.3 | 全篇固定 |
| 课文原句（引文） | KaiTi | 32px | normal | 1.6 | 各任务页 |
| 核心追问（任务页统一层级） | Microsoft YaHei | 36px | bold | 1.5 | 各任务页的主追问，全篇统一 |
| 卡片小标题 | Microsoft YaHei | 26px | bold | 1.4 | 卡片头 |
| 正文 / 辅助说明 | Microsoft YaHei | 26px | normal | 1.6 | 说明文字 |
| 脚注 / 页码 | Microsoft YaHei | 14px | normal | 1.4 | C 区 |

**硬约束核对**：正文 26px ≈ 19.5pt，满足"正文不小于 18pt"；原文引文 32px = 24pt，达到"最好 22pt"；**全篇不出现小于 18pt 的正文字号**（仅页脚 14px 为例外，属标注非正文）。字多一律分页或精简，**不缩字号**。

**巨型数字必须与正文不同字重与字体**：P10 的「4」用 KaiTi bold 96px，正文为 Microsoft YaHei 26px regular，满足。

## 4. 信息密度（本项目为"投屏课件型"，覆盖通用门禁的硬性部分）

通用法则 §4 的"内容页正文字数下限 180"针对阅读型文档；本项目是**给学生看的投屏课件**，用户红线明确要求"每页正文 ≤ 30 字、台下 5 秒内可分辨"。按优先级链（用户显式指令 ≻ 通用法则），本项目**覆盖 §4 的字数下限**，改用下列门禁，其余门禁（视觉锚点、容器填充率、留白上限）继续生效：

| 页面类型 | 正文（说明性文字） | 课文原句 | 视觉锚点 | 留白上限 |
|:-|:-|:-|:-|:-|
| 封面 | ≤ 28 字 | 可引 | 全幅 L1 | 40% |
| 内容页 | **≤ 30 字** | 不设限（原句即主视觉） | ≥ 1 个（≥44px 元素 或 ≥40% B 区面积的图） | 35% |

- **原句不计入"正文"**：课文原句是教学材料与视觉主体，以 32px 大字呈现，本身承担视觉锚点职能。
- **容器填充率 ≥ 85%**：卡片内"标题 + 原句 + 追问"三段垂直填满，尾部元素（追问条）用 `marginTop: 'auto'` 钉底。
- **横向兄弟卡对齐**：P15 三卡的"标题块 / 要求块 / 层级标签"三段 y 轴等高，误差 ≤ 16px。

## 7. 执行与自检记录（成稿后回填）

- **页数与顺序**：15 页全部写入，`ppt/slides/slide1..15.xml` 与页面映射表逐页对应，无缺页、无错序。
- **图片**：4 张 L1 全部嵌入（`ppt/slides/media/image1–4.png`），分别落在 P1 / P2 / P5 / P7，与映射表一致。
- **母版一致**：P2 起全部页面均为 A（100px）/ B（540px）/ C（40px）三区；P1 为封面自定义版式。A 区主标题统一 34px KaiTi bold + 左侧 6×34 朱砂短块，右侧小标统一 18px。
- **字号核对**：全篇正文最小 24px（≈18pt），任务页正文 26–30px，课文原句 30–40px，核心追问 36px，巨型锚点 60–190px。**无小于 18pt 的正文**（14px 仅用于页脚页码与角标）。
- **留白实况**：P3 / P12 / P14 三页居中大字页留白约 40–50%，P2 / P5 / P7 三页因 L1 大图占据半屏留白降至 10–20%，其余页 22–30%。全篇留白比例存在明显起伏，未出现"每页雷同"。
- **与映射表的偏差**（已按实际视觉最优调整，不影响契约字段）：P3 实测留白约 24%（原估 45%）、P10 实测约 30%（原估 38%）、P5 因图为 1152×300 横幅而略高于原估高度。P3 的 A 区未留空，改放 34px 标题「核心问题」以与全篇母版对齐。
- **每页视觉锚点**：P1/P2/P5/P7 由 L1 大图承担，P3 由 140px「悲凉」承担，P10 由 190px「四」承担，P12/P14 由 60–68px 金句承担，P4/P11/P13 由结构图示承担，P15 由三个 56px 层级字母承担。无页依赖 L3 角标充当主视觉。
- **lint**：15 页逐页校验通过（P6 曾因大字「味」越界 30px 被判 `child-containment` 失败，改为贴底对齐后通过）。
