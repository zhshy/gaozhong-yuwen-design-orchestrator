## 四、课件的视觉方案（供复用）

| 要素 | 取值 | 用途 |
|---|---|---|
| 底色 | `#F7F4EC` | 宣纸米，全篇铺底 |
| 主字色 | `#1A1A1A` | 松烟墨，标题与正文 |
| 辅字色 | `#3F4A55` | 青墨，说明性文字 |
| 点睛色 | `#A8351A` | 朱砂，**只用在焦点**：140px 的「悲凉」、190px 的「四」、两个「没有」、板书里的「一点点极微细」 |
| 字体 | 楷体（标题／课文原句／巨型字）＋ 微软雅黑（正文／追问） | 选 Windows 必然可用的字体，避开思源系在教室机器上缺失的风险 |

版式：非对称 11/15（73%）；三区母版（标题区 100 / 内容区 540 / 页脚 40）自第 2 页起一致；相邻页无重复版式；留白刻意做成起伏（P3、P12、P14 大留白 40–50%）。

---

## 五、两点必须说清的事

**1. 课件是「课件版」，里面没有教学设计——这是设计要求，不是缺件。**

按课件版红线，**禁止出现**教学目标、设计意图、预设应对、教师自述、作业答案。这些内容全部在 `故都的秋_教学设计与检测量规.md` 里。要能上屏说课／汇报的版本，需另出**教案版**。

**2. 课件里没有一页是「教学目标」。** 若课堂上习惯先亮目标，需显式说明，否则按红线默认不加。
