## 二、原文

> 从基层上看去，中国社会是乡土性的。我说中国社会的基层是乡土性的，那是因为我考虑到从这基层上曾长出一层比较上和乡土基层不完全相同的社会……乡下人离不了泥土，因为在乡下住，种地是最普遍的谋生办法……土气是因为不流动而发生的。……以农为生的人，世代定居是常态，迁移是变态。

（《乡土本色》，第 1 篇）

## 三、四种读法 · 各做一遍

### 读法一｜接龙读法 —— 他怎么推的

**动作**：把每句压成一个短句，句间填因果词，连成一条链。
**判据**：每个箭头都能填出"因为／所以／但是／于是"之一。填不出＝这一步没推出来。

```
乡下人离不了泥土
      ↓（因为）
____________________
      ↓（所以）
____________________
      ↓（因为）
____________________
      ↓（于是）
____________________
```

### 读法二｜分维读法 —— 差在哪

**动作**：两个概念摆两栏，找 3–5 个可比的维度，一格一个词。
**判据**：每格是"同一把尺子量两边"。一边量不了的维度不算。

| 比什么（维度） | 乡土社会 | 现代社会 |
|---|---|---|
| | | |
| | | |
| | | |

### 读法三｜画圈读法 —— 在哪一格

**动作**：把概念画成位置关系，箭头旁标"其中／导致／相反"。
**判据**：箭头必须有字，没字的箭头等于没画。

```
（在这里画你的圈）
```

### 读法四｜找例读法 —— 今天还成不成立

**动作**：拿书外一个例子套概念，套不上就说清哪一步不合。
**判据**：例子能指回书中一句定义，说得出"第几篇说的"。

| 我的例子 | 套的是哪个概念 | 书中哪一句（第几篇） | **哪里不像** |
|---|---|---|---|
| | | | |

> 注意最后一栏。**只写"很像"不算完成。**
