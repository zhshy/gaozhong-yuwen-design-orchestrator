# 示例：《声声慢（寻寻觅觅）》普通模式单课时

> 一次完整跑通的记录：**普通备课七步 ＋ 一课时 ＋ 抒情词**。
> 四份交付物与课件原样保留。三个教学点取自 `references/poetry-appreciation-angles.md`——叶嘉莹、傅庚生、唐圭璋的读法里**可检查的那一部分**。

## 一、这份示例要验证什么

不是验证"流程走不走得通"（那在别的示例里已经证明过），而是验证一件事：

> **换一套鉴赏角度，同一篇课文能不能跑出不一样的东西。**

上一版这三个点是：叠字分动作／状态、意象分"旧时／如今"两栏、末句入声收束。三条都是**分类**——能让学生做对题，但答完之后学生只多知道了几个类别。

这一版换成三条**关系**：

| 教学点 | 角度 | 来源 | 学生答完之后多知道的是 |
|---|---|---|---|
| 一、叠字的层次与次序 | 分层 ＋ 语序不可移 | 傅庚生《中国文学欣赏举隅》 | "冷冷"挪到"清清"下面，**由外入内这一层就断** |
| 二、意象在前人笔下是什么 | 语码 | 叶嘉莹《唐宋词十七讲》 | "雁""梧桐"在别人笔下的处境，以及这一首怎么转向 |
| 三、末句的收束与争议 | 声情 ＋ 反面评价 | 叶嘉莹讲录所引陈廷焯、许昂霄 | 怎么为一个判断**举证**，包括替对方说出理由 |

## 五、这份示例刻意跑到的四处

### 1. 诊断就是"把皮相摆给学生看"

开课五分钟只问一句"这十四个字好在哪"，把"有节奏""好听""用了叠词"**原样抄在黑板上，一个字不改**。

这正是叶嘉莹、傅庚生、陈廷焯三家共同批评的那三层皮相。等任务一做完再回头看，学生会自己发现那不是答案。

**推翻条件写在教案里**：若有人答出"从'冷冷'到'清清'是从屋子到了心里"，就让他先说，任务一改为追问"还有几级"。

### 2. 一课时只取三条角度

八个角度里取了五条（分层、语序不可移、语码、声情、反面评价），合成三个教学点。

**不取的三条也写清了理由**：兴发感动是体验不是步骤，写进检查项就退化成"要体会感情"；弱德之美是价值判断不是方法，只进说课稿的反思；词体三阶段是教师坐标，对学生不讲术语。

### 3. 有一条专门的卡口：教学点不得只落在技法层

附一的自检表比上一版多了一行：

> 三个教学点答完之后，学生多知道的是**关系**（由外入内／传统与这一首／两种评价），不是术语。

判据是：如果答完之后只多知道一个术语（"用了叠词""借景抒情"），却说不出哪几个字之间是什么关系——退回第 2 步重取。

### 4. 反面评价页（课件第 14 页）

把许昂霄"此词颇带伧气"与陈廷焯"此不过奇笔耳，并非高调"两条投出来，问"你同意吗？举一句为证"。

量规的优秀档要求**替对方说出一个理由**（"说他伧气，大概是因为'怎生''了得'这些口语入词"），再说自己不同意的那一点。**能替对方把理由说清楚，才是真的会判断。**

## 七、怎么用这份示例

1. **先看第五节课时表**：六环节、七列、Σ＝45。检查有没有"汇报漏乘组数""切换写 0"。
2. **再看第四环节**：修订 3 分钟 ＋ 再验证 2 分钟。自己的设计里若找不到"学生改了什么"，就是闭环缺了一环。
3. **最后翻学案的禁装项**：没有教学目标、设计意图、答案、教师活动、方向备注。逐项比一遍，比读十遍规范有用。
4. **想验证角度是否真有用**：拿课件第 6、9、14 三页看——三页问的都是**关系**，不是"这是什么手法"。

## 八、与上一版的差别（同一篇课文，两套角度）

| 项 | 上一版 | 这一版 |
|---|---|---|
| 叠字 | 分动作／状态**两堆** | 分**层**＋追问能否换序（傅庚生七级） |
| 意象 | 分旧时／如今**两栏**，写依据字 | 找**前人的出处**（语码），再比这一首的转向 |
| 末句 | 设计朗读处理 | 朗读处理 ＋ **两条反面评价表态举证** |
| 困难机制 | 概念混淆（把公共义当本篇义） | **缺比较维度**（说不出"比什么好、深在哪"） |
| 诊断任务 | 三个词写形容词 | **"十四个字好在哪"**——与三家的批评正对 |
| 再验证 | 「憔悴损」的主语 | 「守着窗儿，独自怎生得黑」的**动词"得"**（叶嘉莹所讲） |
| 卡口 | 四卡口 | 四卡口 ＋ **技法层卡口** |

> 两版的母本十二节结构、时间表 Σ＝45、检测含量规＋修订＋再验证，这些骨架都没动——**变的是角度，不是流程**。这正是要验证的：流程稳定，换一套读法就能长出不同的课。
