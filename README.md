# 高中语文教学设计总控

> 把五个语文教学技能串成一条固定工作流的编排层。从定依据到读文本、定教学点、落课堂、做检测，七步走完一节课，并把成果切成四份各自独立的 Word（教学设计 / 教案 / 学案 / 说课稿），另配一份上课用的课件。

## 这个技能做什么

**不装新知识，只做编排与分流。**

接到一个完整备课任务后，判断该调哪几个技能、按什么顺序调、每个技能交出什么、交接时检查什么；最后把定稿的**母本**切成四份 `.docx` 交付。

## 编排的五个技能

| 技能 | 解决什么问题 |
|---|---|
| `gaozhong-yuwen-kebiao` | 依据在哪里、要求到什么水平 |
| `sunshaozhen-text-analysis` | 文本怎么读深 |

| `chinese-lesson-design` | 交付格式长什么样 |

## 七步流程

```
0 课情卡   → 课情卡（七组字段，逐字段标四态）   定输入
1 课标     → 任务群 + 水平 + 素养落点      定边界
2 孙绍振   → 文本关键点 + 核心提问          读深
3 王荣生   → 教学点 + 三个台阶              定教什么
4 肖培东   → 教学出口 + 主问题 + 朗读       落课堂
5 语文设计 → 教学设计母本（十二节 + 两附）   成稿
6 检测     → 评价任务 + 评分量规 → 回填母本  母本冻结
7 交付     → 四份 Word + 课件 PPT            交出去
```

**为什么是七步**：五份成果同源。`教学设计` 是母本，`教案`／`学案`／`说课稿`／`课件` 全部由它派生；而母本要等第 6 步的检测与量规回填后才完整——所以派生交付必须排在检测之后。把 Word 生成挤进第 5 步，就会出现"母本还没齐、四份文档已经旧了一版"的返工。

## 课情卡（课情卡，第 0 步）

第 0 步的产出不是"几问几答"，而是一张结构化课情卡：七组字段（课文 / 课型 / 课时 / 学情 / 教师 / 教学语境 / 约束），**每个字段都带一个状态标记**——

| 状态 | 含义 | 对外归入 |
|---|---|---|
| `已确认` | 用户明确说了 | —— |
| `推断` | 用户没说，但可从已有信息推定（须写明依据） | 「请核」 |
| `未提供` | 用户没说，且推不出来 | 「缺失项」 |
| `待核验` | 我方记得但拿不准（原文语句、课时数、教材版本年份） | 「待核对」 |

这是**红线 7「不编造原文和课时数」的落地形态**：一句话的旧约束升级为逐字段的状态标记，**填了不标状态就等于编造**。尤其地，凡涉及**原文文字 / 课时数 / 教材版本年份**三类，**禁止标 `推断`**——这三类错了会渗透到母本与每一份文档，只能由用户确认或查原文补上。

课情卡在四处被下游用到：母本开头回显（`未提供` 与 `待核验` 单列成「待核对事项」）、四份 Word 的页眉、第 3 步「备两头」的学生疑难处、第 7 步的一致性自检基准。

细则（判定决策树、呈现表格模板、交付话术、六种常见违规）见 [`references/lesson-context.md`](references/lesson-context.md)。

## 时间预算：算术相等 ≠ 课堂可行

"Σ 各环节时长 = 课时总时长，误差 0"只是一道加法题。真实课堂翻车的地方不是加错，是**漏项**——把"汇报 2 分钟"一笔带过（实际 4 组要 8 分钟）、忘了学生真写字要几分钟、把环节之间的切换与组织默认成 0。

因此时间表按**七列时间项（六类必计项 ＋ 教师讲授）**逐行拆开：

| 时间项 | 计提规则 |
|---|---|
| 独立阅读 / 静默阅读 | 文言文每 100 字 ≈ 1.5–2 分钟；现代文每 500 字 ≈ 1.5 分钟。写了"学生读一读"就必须给分钟数 |
| 小组讨论 | 并行发生，按**墙钟时间**计（不乘组数）。低于 2 分钟的讨论不成形 |
| **汇报 × 组数** | 串行：`总时长 = 单组时长 × 汇报组数`。**必须写出组数** |
| 教师回应 | 逐组 0.5–1 分钟 × 组数，或集中回应 2–4 分钟 |
| 书写 | 圈画批注 1–2 分钟；任务单每空 3–5 分钟；片段写作 ≥ 5 分钟 |
| 切换 / 组织 | 每环节间 0.5–1 分钟；分组换座 +1 分钟。**45 分钟的课通常 3–6 分钟** |
| 教师讲授·齐读·机动 | 教师讲授与齐读齐背。**必须单列**——不列它，前六类之和小于课时时长，Σ 无从核对 |

两条硬约束：**Σ 误差 0**；**不许压缩学生时间来凑数**——超标时按"教师讲 → 切换 → 汇报组数 → 拓展 → 最后才动阅读与书写"的顺序削减，并注明削减了什么。（认知负荷可选记录，不作门禁。）

细则见 [`references/time-budget.md`](references/time-budget.md)。

## 教学方向 × 学情 × 教师画像

**不替老师定唯一的"最佳教案"。** 同一篇文本给三个可比较的方向：

| 方向 | 重点 | 一句话差异 |
|:-:|---|---|
| 基础型 | 文言基础 + 核心内容 | 先读懂——这句话在说什么，凭什么这么说 |
| 思辨型 | 核心问题 + 观点论证 | 不止读懂——这个论证站得住吗；换成你，会怎么写 |
| 高考型 | 论证结构 + 文言知识 + 迁移训练 | 读懂并且能用——这个结构在考场上怎么认、怎么仿 |

- **主问题下方附一行「方向备注」**，用三句话写出同一问题在三个方向下的问法差异（三句须指向不同层级，各 ≤ 30 字）。备注是提示差异，**不是三份完整教案**。
- **母本第十二节**由原来的一维"分层参数（重点校/普通校/薄弱校）"扩为 **3×3「方向 × 学情」矩阵**；**主打方向那一行必须三格填满**，每格写具体调整点，不写"加深/降低难度"。
- **教师画像**（偏好提问驱动、回避小组讨论、强项/弱项）进入课情卡，并**约束设计**：`回避项` 里的活动形态不得排进台阶主要活动，非用不可就换形态（小组讨论 → 同桌两两互说 + 全班抽样）。画像**只在母本与教案体现，不进学案与课件**；未提供时标 `未提供` 并注明"本次未做教师适配"。

细则见 [`references/differentiation.md`](references/differentiation.md)。

| 文件 | 读者 | 关键约束 |
|---|---|---|
| `篇目_教学设计.docx` | 教师（自用 / 教研 / 备案） | 母本全部十二节 + 两附，其余四份的唯一事实源 |

分节细则、Word 版式与落盘规范、四份互查清单、常见坑见 [`references/deliverables-word.md`](references/deliverables-word.md)。

## 四个卡口

- **卡口一（第 2 步出口）**：每个分析点落到具体语句了吗？说不出是哪几个字、哪个动作，就是没做完
- **卡口二（第 3 步出口）**：教学点 = 文本关键点 × 学生疑难处，重合了吗？
- **卡口三（第 4 步出口）**：每个活动都能指回具体的字词句吗？指不回去，就是飘了
- **卡口四（第 6 步出口）**：每个检测任务都能指回一个教学点吗？题型与体裁匹配吗？

## 分流原则

**用户要的是"一节课"，走全流程；用户要的是"一节课里的某个零件"，直接给那个技能。**

不是所有请求都该走完整流程——上来就跑七步是形式主义。

## 两种交付模式

第 0 步的 **`交付模式`** 字段决定走哪条流程（注意：**不是** `课型.模式`，那个是讲读／自读／活动）：

> 技能头部 `modes:` 里那两个机器可读取值，与本表的对应关系是：`normal_lesson` → `普通备课`，`quality_course` → `精品课`。那两项只用于技能装载，**正文与交付物一律用中文取值**（红线 27）。

| `交付模式` | 触发 | 流程 | 交付 |
|---|---|---|---|
| `普通备课`（默认） | "设计一节课""备公开课""单元整体设计" | **七步** | 四份 Word ＋ 课件 PPT |
| `精品课` | 出现"**报／参评／提交／五件套／微课／目录节点**"任一词 | **九步** | **四件套**（教学设计／学习任务单／课件／作业练习）＋ 微课运行稿 |

**判断口诀**：出现"**报／参评／提交／五件套／微课／目录节点**"任一词 → 精品课；只说"设计一节课" → 普通模式。

### 精品课模式（`精品课`）：学科课程类

给"基础教育精品课"遴选用的模式。**不改教学理论，只让同一份教学设计变成可提交的作品包**——五个底层技能在本模式下**一律不改**。

**只做"学科课程类"一类**。特殊教育／实验教学／人工智能教育／阅读课／科技教育五类**不覆盖**。

九步 ＝ 在原七步上**只插两步**：

```
0 确认输入（＋第八组 提交）
0.5 官方节点锁        ← 新增：不过即停，不做降级
1–6 定依据 → 读文本 → 定教学点 → 落课堂 → 母本 → 教学评一致审计
    ★ 内容冻结（第一次冻结）
7 四件套派生          7.1 教学设计 / 7.2 学习任务单 / 7.3 作业练习 / 7.4 课件 / 7.5 微课运行稿
8 材料一致性 ＋ 门禁一～十 门禁 ＋ 交付报告      ← 新增
    ★ 报送冻结（第二次冻结）
```

**四条核心机制**：

| 机制 | 一句话 | 依据 |
|---|---|---|
| **官方节点锁** | 节点名称须与平台**字符串全等**，不许用相似度判定；拿不到证据**就停** | 官方"原则上同一目录节点只推荐 1 节" |
| **教学评一致** | `目标→教学点→活动→证据→评价` 必须闭环，缺任一即阻断 | 本技能最高优先级门禁四 |
| **五件套同源** | 五件全部从**同一份冻结母本**派生；派生后另查一次一致性 | 两个事实源必然数据不一致 |
| **技术适切** | 判断的不是"用了多少技术"，而是"技术解决了什么教学问题" | 官方"融合应用现代信息技术"，定位是**服务教学、不是技术展示** |

**明确不做**（属"作品制作与合规"，由录制与提交环节承担）：

- ❌ **不规定视频制作规范**（时长／分辨率／片头／字幕／体积／命名）——本技能不产出视频文件
- ❌ **不做原创性与版权材料清单**——与"这节课怎么教"无关
- ❌ 不生成 `.mp4`、不预测得分、不估获奖概率

规格见 `references/jpk-high-school-chinese/`（11 个文件），**执行前先读该子目录的 `README.md`**。

`examples/` 下有两份完整跑通的记录，覆盖两种差别最大的场景：

先看《声声慢》：**普通备课七步 · 单课时 · 抒情词**，四份交付物与课件原样保留，可用来对照产出形态：

| 内容 | 文件 |
|---|---|

| 教学设计 · Word 成品（A4／宋体小四／1.5 倍行距／页眉页脚） | `examples/声声慢/声声慢_教学设计.docx` |
| 教案（五列课时表，六环节） | `examples/声声慢/声声慢_教案.md` |
| 学案（十栏 ＋ 诗歌诵读标注栏） | `examples/声声慢/声声慢_学案.md` |
| 说课稿（九节，15 分钟，正文 2747 字） | `examples/声声慢/声声慢_说课稿.md` |
| 课件成品 · 16 页 · 投给学生用 | `examples/声声慢/课件/声声慢.pptx` |
| 课件源工程（叙事稿／设计稿／逐页源文件） | `examples/声声慢/课件/` |

**这份示例重点演示四处**：

- **鉴赏角度换血**——三个教学点取自 `poetry-appreciation-angles.md`：分层＋语序不可移（傅庚生）、语码（叶嘉莹）、声情＋反面评价（陈廷焯、许昂霄）。三条都是**关系**，不是分类；
- **诊断就是取证**——开课只问"这十四个字好在哪"，把"有节奏""好听""用了叠词"原样抄黑板；推翻条件写在教案里；
- **修订与再验证单列六分钟**——把"很有层次"改成"从哪一级走到哪一级"，再用「守着窗儿，独自怎生得黑」的动词"得"换文本验证；
- **技法层卡口**——附一多一行自检：答完之后学生多知道的是关系，不是术语；只多知道术语就退回第 2 步重取。

> 同一篇课文另有上一版（按分类讲：叠字分两堆、意象分两栏）。两版的十二节结构、Σ＝45、检测含修订与再验证的骨架都没动，**变的是角度不是流程**——差别对照见示例 README 第八节。

**输入参数**：单篇精读 ｜ 1 课时 ｜ 普通校 ｜ 课标按三级水平（目标线＝水平二）。

**读法**：先看第五节课时表（六环节、七列、Σ＝45），检查有没有"汇报漏乘组数""切换写 0"；再看第四环节"修订与再验证"，如果自己的设计里找不到"学生改了什么"，那就是闭环缺了一环；最后翻学案的禁装项——它没有教学目标、设计意图、答案、教师活动、方向备注，逐项比一遍，比读十遍规范有用。

> 注意：课件是**课件版**（投给学生），按红线**不含**教学目标、设计意图、预设应对、作业答案——这些在教学设计 md 与三份内容稿里。
>
> **精品课模式的示例不在当前版本**：早期版本里另有一份《劝学》的精品课九步完整记录（申报信息、节点卡、母本、一致性矩阵、三件提交件、课件页清单、微课运行稿、门禁报告，共 10 个文件），已随本次示例更替移除，避免两套示例并置造成误读。需要时从标签取回：

### 第二个示例：《乡土中国》导读课

`examples/乡土中国/` 跑的是**整本书阅读 · 导读课 · 1 课时 · 学术著作**，与上一份的差别在于：它不教内容，只给读法与进度。

| 内容 | 文件 |
|---|---|
| 教学设计（母本，十二节 ＋ 两附） | `examples/乡土中国/乡土中国_教学设计与检测量规.md` |
| 教学设计 · Word 成品 | `examples/乡土中国/乡土中国_教学设计.docx` |
| 教案（六环节五列课时表） | `examples/乡土中国/乡土中国_教案.md` |
| 学案（八栏，含五周进度表与概念卡） | `examples/乡土中国/乡土中国_学案.md` |
| 说课稿（九节，15 分钟，正文 2828 字） | `examples/乡土中国/乡土中国_说课稿.md` |
| 课件成品 · 19 页 · 4 页整页水墨背景 | `examples/乡土中国/课件/乡土中国.pptx` |
| 课件源工程（叙事稿／设计稿／逐页源文件／5 张配图） | `examples/乡土中国/课件/` |

**这份示例演示四件事**：

- **四种读法**——接龙（管论证）／分维（管辨析）／画圈（管结构）／找例（管迁移），每种配一条判据，判据做不到就是没做；
- **十四篇分派表**——把读法从操作变成判断，且**可反驳**："你觉得哪篇配错了，指得出论证形态我就改"；
- **五周进度表**——整本书阅读最该有、最常缺的一页。八份获奖课例一份也没有；
- **概念卡第五栏"一个反例"**——概念迁移的价值在边界不在相似，这栏不许空。

本单元的八节获奖课例（陈媛媛／刘建钰／朱亮／宫睿哲各两节）的读法，逐条被吸收成这四种；**它们共同的缺口是"没有一节课把读法本身当教学内容"**，本课补的就是这个位置。详细对照见 `examples/乡土中国/README.md` 第四节。

## 版本与更新

- **版本号**遵循语义化版本，写在 [`SKILL.md`](SKILL.md) 的 frontmatter `version:` 字段；**每个版本对应一个 git 标签**（`v1.0.0` …），逐版变更见 [`CHANGELOG.md`](CHANGELOG.md)。
- **版本号含义**：主版本＝目录结构或不兼容的流程改动；次版本＝新增规范 / 新增 `references/` / 新增红线；修订版＝文字订正与表述统一。
- **按版本安装**（可复现的取版方式）：

```bash
# 取最新
git clone https://github.com/zhshy/gaozhong-yuwen-design-orchestrator.git
# 取指定版本
git clone --branch v2.4.3 --depth 1 \
  https://github.com/zhshy/gaozhong-yuwen-design-orchestrator.git
# 不装 git，也可直接取该版本的 tar 包
curl -LO https://codeload.github.com/zhshy/gaozhong-yuwen-design-orchestrator/tar.gz/refs/tags/v2.4.3
```

## 什么是 Skill

Skill 是给 AI 助手加载的专业知识包：一个 `SKILL.md` 定义触发条件与工作流程，`references/` 存放按需加载的细节文件。加载后助手会按既定流程工作，而不是即兴发挥。

本仓库技能遵循 Agent Skills 规范：YAML frontmatter + Markdown 正文 + 渐进式披露的 references。
